# Set up columns

Columns are the stages a card moves through, from left to right.

## Add a column

1. Click **Add column** at the end of the board.
2. Type the column name and press Enter.

## Rename, recolor, or limit a column

1. Open the column's **Column actions** menu and choose **Edit column**.
2. Change the **Name** or **Color**.
3. To cap how many cards the column should hold, enter a **Card limit**. Leave it empty for no limit.
4. Click **Save**.

The column header then shows the count against the limit, for example `3 / 2`, and turns red when the column is over. The limit is a warning only: you can still add cards.

## Reorder columns

Drag a column by its handle to a new position.

## Delete a column

Open **Column actions**, choose **Delete column**, and confirm. The column's cards are deleted permanently with it, so move any you want to keep first.
