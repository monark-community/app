# Find cards

## Filter a board

Filtering hides the cards that don't match, without moving anything.

1. Click **Filter cards** to open the query bar.
2. Type conditions, for example `assignee:@me priority:>=HIGH due:@startOfWeek..@endOfWeek`.

You can filter on title, description, status (the column), assignee, reviewer, priority, due date and estimate. See [Query syntax](../../../../docs/reference/query-syntax.md) for everything you can write.

## Save a filter as a view

1. With a filter applied, open **Views** and choose **Save current query…**.
2. Name the view. Turn on **Share with everyone** to let everyone who can see the board use it.
3. Click **Save**.

Pick a view from **Views** to apply it again.

## Search every board

Press ⌘K (Ctrl+K on Windows and Linux) and type part of a card's title. Results come from every board you can see, each labeled with its board.
