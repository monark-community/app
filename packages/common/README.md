# @monark/common

App-internal runtime and shared primitives. Backend-only runtime; types are safe to import from anywhere.

## What lives here

- **Event bus runtime** ([`src/events.ts`](src/events.ts)); `emit` + `on` with in-process handler dispatch and error-isolated callbacks.
- **DomainEvent contract** ([`src/contracts/events.ts`](src/contracts/events.ts)); `DomainEventBase` interface plus the re-exported `DomainEvent` union. The union is generated by `pnpm gen:events`; do not edit `events.generated.ts` by hand.
- **tRPC primitives** ([`src/trpc.ts`](src/trpc.ts)); `t`, `router`, `publicProcedure`, `middleware`, `TrpcContext`. Every module's server entry imports `router` from here.
- **Error hierarchy** ([`src/errors.ts`](src/errors.ts)); `AppError` + `NotFoundError` / `UnauthorizedError` / `ForbiddenError` / `ValidationError` / `ConflictError`.
- **Result type** ([`src/result.ts`](src/result.ts)); `Result<T, E>` with `ok`/`err` constructors.
- **Logger** ([`src/log.ts`](src/log.ts)); pino instance with default service metadata.

## Public entry points

| Import path                       | What it exports                                             |
| --------------------------------- | ----------------------------------------------------------- |
| `@monark/common`                  | barrel (errors, result, logger, emit/on, DomainEvent types) |
| `@monark/common/events`           | event-bus runtime only                                      |
| `@monark/common/contracts/events` | `DomainEventBase`, `DomainEvent`                            |
| `@monark/common/trpc`             | tRPC primitives                                             |
