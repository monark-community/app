# @monark/common

App-internal runtime and shared primitives. Backend-only runtime; types are safe to import from anywhere.

## What lives here

- **Event bus runtime** ([`src/events.ts`](src/events.ts)); `emit` + `on` with in-process handler dispatch and error-isolated callbacks.
- **DomainEvent contract** ([`src/contracts/events.ts`](src/contracts/events.ts)); `DomainEventBase` interface plus the re-exported `DomainEvent` union. The union is generated by `pnpm gen:events`; do not edit `events.generated.ts` by hand.
- **tRPC primitives** ([`src/trpc.ts`](src/trpc.ts)); `t`, `router`, `mergeRouters`, `publicProcedure`, `middleware`, `TrpcContext`, plus the `APP_TO_TRPC_CODE` map that surfaces `AppError.code` as a tRPC error code. Every module's server entry imports `router` from here.
- **Error hierarchy** ([`src/errors.ts`](src/errors.ts)); `AppError` + `NotFoundError` / `UnauthorizedError` / `ForbiddenError` / `ValidationError` / `ConflictError`.
- **Result type** ([`src/result.ts`](src/result.ts)); `Result<T, E>` with `ok`/`err` constructors.
- **Logger** ([`src/log.ts`](src/log.ts)); pino instance with default service metadata.
- **Cursor pagination** ([`src/pagination.ts`](src/pagination.ts)); the shared `PaginationArgs` / `Paginated<T>` contract for every "GET ALL" list method, plus `cursorFindArgs` / `toPage` / `resolveLimit` helpers and the `DEFAULT_PAGE_SIZE` / `MAX_PAGE_SIZE` / `PAGE_SIZE_OPTIONS` constants. Dependency-free, so client code can import the subpath.
- **Event-type registry** ([`src/event-registry.ts`](src/event-registry.ts)); `registerEventTypes` + the operator-facing descriptor lookups (`listEventTypes` / `listEventTypesByModule` / `getEventTypeDescriptor` / `eventFieldsFor`) plus org-scoped visibility (`registerOrgScopedEventTypeVisibility` / `orgVisibleEventTypes`) so per-org event types stay hidden from other orgs' webhook pickers.
- **Outbound-URL / SSRF guard** ([`src/http.ts`](src/http.ts)); `assertOutboundUrlSafe` (scheme + literal private/reserved-IP checks) and `safeFetch` (adds a production DNS-resolution guard, timeout, `redirect: "manual"`, and optional `maxBytes` cap). Server-only.
- **Rate limiter** ([`src/rate-limit.ts`](src/rate-limit.ts)); `checkRateLimit` over a Postgres-backed token bucket (`RateLimitBucket` table), with the pure `stepTokenBucket` and a swappable `RateLimitStore` (`setRateLimitStore`). Server-only.
- **Crypto** ([`src/crypto.ts`](src/crypto.ts)); AES-256-GCM `encrypt` / `decrypt`, `loadEncryptionKey` (per-feature key from env), and `timingSafeEqualHex`. Server-only.
- **Dev event tap** ([`src/dev-event-log.ts`](src/dev-event-log.ts)); `installDevEventTap` / `recentDevEvents`, a dev-only wildcard subscriber ring buffer for the event-bus overlay.

| Import path                       | What it exports                                                                                                                                    |

| `@monark/common`                  | barrel (errors, result, logger, emit/on + `WILDCARD_EVENT_TYPE`, event-type registry, cursor-pagination helpers, dev event tap, DomainEvent types) |
| `@monark/common/events`           | event-bus runtime only                                                                                                                             |
| `@monark/common/contracts/events` | `DomainEventBase`, `DomainEvent`                                                                                                                   |
| `@monark/common/trpc`             | tRPC primitives                                                                                                                                    |
| `@monark/common/pagination`       | cursor-pagination types, helpers, constants (dep-free)                                                                                             |
| `@monark/common/http`             | `safeFetch` + `assertOutboundUrlSafe` outbound-URL / SSRF guard (server-only)                                                                      |
| `@monark/common/rate-limit`       | `checkRateLimit` token-bucket limiter + `RateLimitStore` (server-only)                                                                             |
| `@monark/common/crypto`           | AES-256-GCM `encrypt` / `decrypt` + `loadEncryptionKey` / `timingSafeEqualHex` (server-only)                                                       |
