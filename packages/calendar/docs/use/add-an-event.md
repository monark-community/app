# Add an event

1. Open the **New event** form:
   - In Day or Week view, click an empty time slot.
   - In Month view, click an empty part of a day.
   - In Agenda view, click **Add event**.
2. Choose a **Type**: **Standard** has a start and an end time, **Punctual** marks a single moment, and **Full day** covers whole days.
3. Enter a **Title**, then set the date and times.
4. Optionally add a **Description**, a **Location** and **Participants**. You're listed as a participant already. Pick people from the suggestions, or type a name and press Enter.
5. Choose the **Calendar** the event belongs to.
6. Click **Create**.

If the event overlaps another on the same calendar, the form warns you, for example "This overlaps with "Standup"." The warning doesn't stop you from saving.

## Span several days

In Month view, drag across the days the event covers. The form opens as a **Full day** event over those days.

## Add a reminder

1. In the form, click **Add reminder**.
2. Set how long before the event: a number and a unit (minutes, hours, days or weeks).

Add more reminders the same way. When one is due, everyone who can see the calendar gets an in-app notification; selecting it opens the event's day. Reminders aren't sent by email, and participants aren't notified of the event itself.
