# Import and export events

Move events between Monark and another calendar app, such as Google Calendar, Outlook or Apple Calendar, using an `.ics` file.

## Export a calendar

1. Click **⋯** next to the calendar in the sidebar.
2. Choose **Export (.ics)**. Your browser downloads `calendar.ics` with that calendar's events.
3. Import the file in the other calendar app.

## Import events

1. Export an `.ics` file from the other calendar app.
2. In Monark, click **⋯** next to the calendar the events should go into, and choose **Import (.ics)**.
3. Choose the file. A message confirms how many events were imported.

Good to know:

- One import brings in at most 500 events; the rest of the file is skipped.
- A recurring event comes in as a single, one-time event. Its repeats aren't imported, and the message says how many events this affected.
