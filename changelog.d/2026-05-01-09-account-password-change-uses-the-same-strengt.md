- 2026-05-01: Account password change uses the same strength algorithm as signup. Server-side [`changePasswordAction`](<monark/app/services/web/src/app/(authed)/account/actions.ts>) was previously a length-only gate (`newPassword.length < 12`) ; now it calls `auth.checkPassword` (full offline rules + HIBP) with the user's email + displayName for context, the same path signup runs through. Client-side [password-section.tsx](<monark/app/services/web/src/app/(authed)/account/password-section.tsx>) gains a live `<PasswordStrengthMeter>` and a `disabled={!strength.ok}` submit button, mirroring [signup-form.tsx](<monark/app/services/web/src/app/(anon)/signup/signup-form.tsx>). The static `account.password.minLengthHint` text is gone ; the meter is now the source of truth for strength feedback.
