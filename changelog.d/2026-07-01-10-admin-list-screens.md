- 2026-07-01: Admin list screens — mobile-first detail panel + filter toolbar. The table ↔ detail-panel pattern and the toolbar above it were desktop-only in feel ; on a phone the right-hand `Sheet` was a cramped sliver and the loose `Select` filters overflowed the row. `TableDetailLayout` now renders the panel **full-screen and modal** below `md` (overlay + `useIsMobile`-gated sizing) instead of a persistent non-modal side sheet ([table-detail-layout.tsx](monark/app/services/web/src/components/patterns/table-detail-layout.tsx)) ; selecting a row takes over the screen, so `DataTable`'s primary cell drops inline-edit on mobile and lets the label open the panel (the open-panel icon also stays visible without hover) ([data-table.tsx](monark/app/services/web/src/components/patterns/data-table/data-table.tsx)), and `PanelHeaderBar` hides its open-full-page link there since the panel is already full-screen ([panel-header-bar.tsx](monark/app/services/web/src/components/patterns/panel-header-bar.tsx)). The toolbar filters collapsed behind a single icon button 8px from the search field : `FilterBar` gained explicit `search` / `filter` / `actions` slots ([filter-bar.tsx](monark/app/services/web/src/components/patterns/filter-bar.tsx), search fills the row on mobile and holds ~350px on desktop), and a new declarative [`FilterMenu`](monark/app/services/web/src/components/patterns/filter-menu.tsx) takes `FilterConfig[]` and renders a dropdown of radio groups on desktop / a full-screen modal (title + top-right close) on mobile, with an active-filter count badge on the trigger. Reused the shared `dialog.tsx` `mobileFullScreen` prop (added a `hideClose` option) for the modal. Ported [projects-list.tsx](<monark/app/services/web/src/app/(authed)/projects/projects-list.tsx>) (status + industry filters) and [industries-list.tsx](<monark/app/services/web/src/app/(authed)/industries/industries-list.tsx>) (archived filter, replacing the show/hide toggle) onto the slots ; new shared `filters.*` i18n namespace + industries `archivedFilterLabel` / `activeOnly` / `includeArchived` keys in both locales.
