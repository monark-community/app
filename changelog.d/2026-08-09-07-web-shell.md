- 2026-08-09: Web shell — consolidated Admin / Account / Data's independently hand-rolled section chrome into one shared [`SectionShell`](monark/app/services/web/src/components/section-shell.tsx), and added a scroll-linked mobile detail bar. Previously each of the three `(authed)/<section>/layout.tsx` files separately composed `PageLayout` (or `SidebarRail` directly) + a secondary-nav bar + its own bounded-scroll wrapper — three copies of the same shell, drifted in small ways (`data`'s wrapper was only `xl:`-gated, its content offset was `pl-78` vs `PageLayout`'s exact `pl-72`), and the previous entry's `pinned`-prop fix on the now-deleted `SecondaryTabsBar` had to be threaded through each copy individually. `SectionShell` (`sidebar` for the `xl+` rail, `secondaryNav` for the mobile strip, `variant: "centered" | "full"` for `PageLayout`'s old max-w-2xl vs Data's edge-to-edge tables) is now the only thing each layout mounts ; `PageLayout`, `SecondaryTabsBar`, and the three thin per-section tab-bar wrappers (`AdminTabsBar`, `DataTabsBar`) are deleted.

  New on top of the consolidation : a scroll-linked **detail bar**. `PageHeader` — the existing inline `<h1>` + back-link block already used by every detail page (model editor, org/role/webhook editors, data record full pages, delivery detail) — now also registers its title + `backHref` with the nearest `SectionShell` via a new `useSectionDetailHeader` hook whenever it has a `backHref` (purely additive ; the inline block is unchanged). On mobile, the shell renders the secondary-nav row and (when registered) a compact detail-bar row stacked below the AppBar — 3 rows at rest. The nav row's height is driven by a `grid-template-rows` `1fr`↔`0fr` transition (real box height, not a transform, so it naturally pushes/pulls siblings) tied to `<main>`'s own scroll direction, not `window`'s (window can't scroll ; see the previous entry) : scrolling down collapses the nav row to zero height, and the detail bar rises into the vacated slot (2 rows) ; scrolling back up (or near the top) restores the nav row (3 rows again). Pages without a registered detail header keep the plain nav-only collapse behavior. `tsc` + `eslint` + 279 web tests green ; verified end-to-end with Playwright at an iPhone-13 viewport across all three sections (bounding-box measurements of the row swap on scroll, plus visual screenshots).
