- 2026-07-25: DataTable — the selection checkbox column is now a true fixed 64px. With `table-fixed` + `min-w-full`, a table narrower than its container scaled **every** column up proportionally — so the fixed 64px checkbox column ballooned (~1.5×) on narrow tables like the industries model. Fixed by appending a single width-less trailing spacer cell to each row ([data-table.tsx](monark/app/services/web/src/components/patterns/data-table/data-table.tsx)) : under fixed table layout the lone auto-width column absorbs all the slack, so the `select` / `actions` chrome columns _and_ every data column (including the still-fully-resizable primary) keep exactly their set widths, with the leftover space falling to the right of the last column. Empty/error rows span `+1` for the spacer. `tsc` + `eslint` green (couldn't re-screenshot — the shared Vite harness bundle is currently broken by an unrelated in-progress kanban import).
