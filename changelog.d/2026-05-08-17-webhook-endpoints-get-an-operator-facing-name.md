  - **Schema** : new `name TEXT NOT NULL` column on `WebhookEndpoint` ([packages/db/prisma/schema.prisma](monark/app/packages/db/prisma/schema.prisma)). Migration [20260508100000_add_webhook_name](monark/app/packages/db/prisma/migrations/20260508100000_add_webhook_name/migration.sql) lands the column in three steps so existing rows survive : add nullable, backfill from URL (strip scheme, trim trailing slash, cap at 80 chars), promote to NOT NULL. Defensive fallback to `Webhook <id-prefix>` for any degenerate row that ended up empty after the regex.
  - **Server** : new `hasSysadminAssignment` data helper + `rbac.isSysadmin` tRPC procedure ([packages/rbac/src/server/{data.ts,index.ts}](monark/app/packages/rbac/src/server)) — distinct from `isAdmin` which lights up for org-tier admins too. `webhooks.create` now requires `name: 1..80 chars` ; `webhooks.update` accepts an optional name patch ; the `webhook.endpoint-updated` event's `changed` enum picked up `"name"` ([packages/webhooks/src/contracts/events.ts](monark/app/packages/webhooks/src/contracts/events.ts) + [packages/webhooks/src/server/{router.ts,data.ts}](monark/app/packages/webhooks/src/server)).
