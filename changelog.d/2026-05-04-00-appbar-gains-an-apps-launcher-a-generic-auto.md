- 2026-05-04: AppBar gains an Apps launcher + a generic auto-derived breadcrumb. New 3x3-grid icon button to the left of the notifications bell opens a [`<AppLauncher>`](monark/app/services/web/src/components/app-launcher.tsx) popover listing every Monark product surface (Core today ; accounting / trading / RWA / etc. layer in via [services/web/src/config/apps.ts](monark/app/services/web/src/config/apps.ts) as those subdomain-hosted apps come online — `external: true` opens in a new tab so the user keeps their session here ; the current app's card carries a "Current" pill and points at "/"). The previous single-segment [`<AppBarTitle>`](monark/app/services/web/src/components/app-bar.tsx) is gone ; the new [`<AppBarBreadcrumb>`](monark/app/services/web/src/components/app-bar-breadcrumb.tsx) walks `usePathname()` segments and renders `{primary nav feature} / {secondary section} / {last subsection}` automatically — e.g. `/admin/organizations/abc` reads "Admin / Organizations / {orgDisplayName}". Deeper paths collapse the middle behind an ellipsis ("Admin / Organizations / … / Danger Zone"). Static segments resolve through the new `appBar.breadcrumb.<segment>` i18n dictionary (kebab-case → Title Case fallback for unmapped segments, no warnings) ; dynamic id segments (anywhere a route lives at `[id]`) dispatch to a per-pattern crumb component that fetches the entity name through tRPC — `<UserNameCrumb>` reads `users.adminGetUser`, `<OrgNameCrumb>` reads `organizations.adminGet`. New `[id]` patterns register by adding one branch in `pickCrumbForSegment` ; everything else flows through `<StaticCrumb>` with no per-page wiring. **i18n** (en + fr) : new `appBar.apps.{triggerAria, aria, title, subtitle, currentBadge, items.core.{name, tagline}}`, new `appBar.breadcrumb.{account, notifications, admin, users, organizations, organization, rbac, setup}` ; dropped `appBar.sections.*` (the `<AppBarTitle>` it fed is gone, the admin-pin label in [primary-nav-menu.tsx](monark/app/services/web/src/components/primary-nav-menu.tsx) now reads from `appBar.breadcrumb.admin`).
