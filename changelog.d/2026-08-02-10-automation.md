- 2026-08-02: Automation — **variables now work on select / boolean / number config fields (value ↔ variable toggle).** Those controls (a dropdown, a switch, a numeric spinner) can't hold a `{{ }}` token, so there was no way to feed them a variable — the picker only inserts into a text box. Each such field ([automation-editor.tsx](<monark/app/services/web/src/app/(authed)/automation/[id]/automation-editor.tsx>) `ConfigField`) now shows a small `{{ }}` toggle that swaps the native control for a plain text input accepting a reference (and wired to the click-to-insert picker like every other text field). It's forced on automatically whenever the stored value already is an expression, so a saved variable never silently disappears from a dropdown that has no matching option. Applies to `select` / `data-model` / `user` / `secret` / `boolean` / `number` ; `text` / `textarea` / `json` already took references, and `event-type` (trigger-only, drives the event-fields UI) / `schedule` (structured builder) are intentionally excluded. New i18n keys `useVariable` / `useFixedValue` / `variablePlaceholder` (en + fr). `web` typecheck + lint + `check:i18n` green.
