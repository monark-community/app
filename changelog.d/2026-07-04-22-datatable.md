- 2026-07-04: DataTable — config menu reworked into Columns + Sorting submenus. The sliders (⚙) button previously opened a flat `DropdownMenu` of visibility checkboxes, and reordering was only possible by dragging the column _headers_ (undiscoverable). It now opens a **Popover** ([data-table.tsx](monark/app/services/web/src/components/patterns/data-table/data-table.tsx)) with a root list that drills into two sub-panels : **Columns** — one row per data column with a **drag handle on the left** (reorder) and a **visibility checkbox** ; and **Sorting** — **multi-level**: an ordered priority list of active sort fields, each with a drag handle to reprioritize, an Ascending / Descending toggle, and a remove (×) button, plus an "Add sort field" section listing the remaining sortable columns. It's wired to the table's `sorting` state (already an ordered array, so multi-column sort works natively) so header-click sort and the menu stay in sync. A Popover hosts it rather than a menu because dnd-kit's pointer-drag fights a `DropdownMenu`'s item / roving-focus semantics ; the Columns panel and the Sorting priority list each use a vertical `SortableContext`, and column order + visibility + the full sort priority persist to localStorage. Header-drag still works. The Sorting submenu is opt-in via a new optional `labels.sort` object (all-or-nothing so there are no English fallbacks in the component) ; added `table.{sorting,sortAscending,sortDescending,sortNone,sortAddField,sortRemove}` i18n (en + fr) and passed `sort` from all 9 `DataTable` consumers. The drag handle's accessible name reuses the column's already-translated header. Added `table-config-{root,columns,sorting}` + `table-sorting-active` stories to the [screenshot harness](monark/app/services/web/tools/screenshots/stories.tsx) ; web `tsc` + `eslint` green, 222 tests pass.
