- 2026-08-04: Mobile UX — a shared-primitive pass so touch ergonomics improve app-wide without changing desktop density. (1) **Touch targets** — added a `pointer-coarse:min-h-11` (and `min-w-11` for icon buttons) floor to the shared [`Button`](monark/app/services/web/src/components/ui/button.tsx) size variants, [`Input`](monark/app/services/web/src/components/ui/input.tsx), and [`SelectTrigger`](monark/app/services/web/src/components/ui/select.tsx). It keys off `@media (pointer: coarse)` (touch/pen), not the viewport, so a mouse keeps today's compact 36px controls while phones/tablets get a ~44px hit area — and because it's a `min-*`, a control with an explicit smaller height (the DataTable row-actions `…` `h-7`, the file-field remove `h-5`) keeps its small _visual_ while the tap area floors at 44px. Applied the same to the raw `<button>` sort/column-row controls in [panels.tsx](monark/app/services/web/src/components/patterns/data-table/panels.tsx) (not `Button`-based, so no cascade). (2) **Safe-area** — [`DirtyFormBar`](monark/app/services/web/src/components/dirty-form-bar.tsx) now adds `env(safe-area-inset-bottom)` to its bottom padding in both viewport + container modes, so the save row clears the iOS home indicator (0 elsewhere). (3) **Dialog/Sheet** — the shared close button grew from a ~16px glyph to a padded ~36px box (44px on touch) in [dialog.tsx](monark/app/services/web/src/components/ui/dialog.tsx) + [sheet.tsx](monark/app/services/web/src/components/ui/sheet.tsx), and a plain (non-`mobileFullScreen`) dialog now keeps a 1rem gutter + rounded corners on a phone instead of going edge-to-edge. (4) **AutoForm sticky save** — [`FormActionsFooter`](monark/app/services/web/src/components/patterns/form-actions-footer.tsx) gained a `stickyOnMobile` option (a floating rounded action bar pinned to the scroll bottom with safe-area, reverting to the inline row at `md+`), adopted by [`AutoForm`](monark/app/services/web/src/components/fields/auto-form.tsx) so Save is reachable without scrolling a long form to its end. The screenshot harness now emulates touch (`hasTouch`/`isMobile`) on the mobile viewport ([capture.mjs](monark/app/services/web/tools/screenshots/capture.mjs)) so `pointer-coarse:` sizing + `hover:`-less touch states render; new `mobile-ux` + `mobile-dialog` stories verify the touch floors, the sticky save bar, and the dialog gutter/close. web `tsc` (0 errors) + `eslint` + 248 tests green.
