- 2026-05-07: Webhook routing fix for user-tied events. Bug : `user.signed-in`, `user.signed-out`, and every other event whose payload carries a `userId` but no `organizationId` were silently dropped for org-scoped endpoints — the previous routing filter only matched on `event.organizationId === endpoint.organizationId`, so events with no org id never reached non-platform endpoints. Most operators create org-scoped endpoints (the picker's default in single-tenant deploys), so user-tied events never fired.
  - **Three-rule routing** in [packages/webhooks/src/server/subscribers.ts](monark/app/packages/webhooks/src/server/subscribers.ts) replaces the single-rule org filter :
    1. **Platform-tier** (`organizationId = null`) — receives every match. Unchanged.
    2. **Direct org match** — event payload's `organizationId` equals the endpoint's. Unchanged.
    3. **User-tied membership match** (NEW) — event has a `userId` but no `organizationId` ; subscriber looks up the user's active `OrganizationMembership` rows (excluding `leftAt`) and fans out to every org-scoped endpoint whose org the user belongs to.
  - **Lazy membership lookup.** The new DB roundtrip only fires when there's at least one org-scoped endpoint that needs it AND the event is user-tied. Platform-only or org-direct events skip the lookup entirely. `findUserMemberOrgIds(userId)` lives in [packages/webhooks/src/server/data.ts](monark/app/packages/webhooks/src/server/data.ts) ; the subscriber caches the result for the life of one event so multiple matching endpoints share one query.
  - **Effect.** Org-scoped endpoints subscribed to `user.signed-in` / `user.signed-out` / `user.password-changed` / `totp.enabled` / `notification.created` / etc. now receive deliveries for every member of their org. Former members (rows with `leftAt` set) are excluded — a user's later events don't leak to an org they've left.
  - Routing semantics documented in [packages/webhooks/README.md § Routing semantics](monark/app/packages/webhooks/README.md#routing-semantics). `pnpm typecheck` stays clean across all 15 packages.
