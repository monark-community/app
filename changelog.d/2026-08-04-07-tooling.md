- 2026-08-04: Tooling — `pnpm enable:dev-flags` to turn a set of feature flags on for a dev instance. New [tools/enable-dev-flags.ts](monark/app/tools/enable-dev-flags.ts) writes a **global override** (`enabled: true`) for `data-models.query-language`, `public-api.enabled`, and `public-api.service-accounts` — the same thing an operator does at `/admin/feature-flags`, scripted + idempotent. Each flag's registered `defaultOn` stays `false`, so production deploys are unaffected ; the tool only flips the flags on in the DB it points at, and refuses to run with `NODE_ENV=production`. It syncs the flag definitions first (so the override's `FeatureFlag` FK resolves on a fresh DB), then upserts the overrides via `setOverride(key, {}, true, …)`. Added `@monark/data-models` / `@monark/public-api` / `@monark/feature-flags` as workspace deps of the root package so the tool resolves them under `tsx`, and a `enable:dev-flags` package script (mirrors `sysadmin`). tools `tsc` (0) + `eslint` green ; ran against the local dev DB and verified the three global overrides landed.
