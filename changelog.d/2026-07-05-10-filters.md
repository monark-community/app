Applied in both the desktop field sub-menu (`DesktopFilterControl` — the `DropdownMenuItem` gains `sticky bottom-0` + `bg-popover` + a top border, replacing the plain separator) and the mobile / collapsed control (`FilterFieldControl` — the reset `Button` gains `sticky bottom-0` + its host surface bg) in [filter-menu.tsx](monark/app/services/web/src/components/patterns/filter-menu.tsx). The `filter-menu-clear` story now uses an 18-option field to exercise it. `tsc` + `eslint` + 222 tests green.
