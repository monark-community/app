- 2026-08-04: Testing / CI — two drift guards + web logic tests. Added `gen:schema --check` ([gen-schema.ts](monark/app/tools/gen-schema.ts)) and wired it into the CI codegen-drift step — this had been a real gap: the header claimed schema.prisma was drift-checked, but only `gen:events` / `gen:routers` were, so a base/fragment edit that skipped `pnpm gen:schema` would slip through. Added a migration↔schema drift gate ([check-migrations.ts](monark/app/tools/check-migrations.ts), `pnpm check:migrations` + a `migration-drift` CI job with a Postgres service) : it replays every committed migration into a shadow DB and diffs the result against schema.prisma, failing on any change beyond a small allowlist of divergences the Prisma datamodel structurally can't express (the DataRecord jsonb GIN index built in raw SQL ; the TrustedDevice `expiresAt` dbgenerated default's cosmetic reformatting). Catches a modeled change shipped without a migration, or a migration hand-edited away from the schema. On the web side, added unit tests for the untested logic-bearing lib utilities — `color-utils` (hex→rgb/hsl/cmyk, all branches), `format-time` (relative-time bucketing), `dev-host-rewrite` (the LAN-dev loopback swap) — and the last untested server-action file, `admin/users/admin-actions.ts` (avatar/banner upload gates + the admin password-reset flow) ([tests/lib](monark/app/services/web/tests/lib), [admin-users-actions.test.ts](monark/app/services/web/tests/actions/admin-users-actions.test.ts)) : those files went to 92–100 %, though the headline web number barely moves since coverage instruments the whole `src` tree (page/component code is e2e's job), so the floor stays at 5 for now. 31 new web tests (279 total) ; lint + typecheck green.
