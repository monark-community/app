- 2026-07-28: Secrets — new **`@monark/secrets` core module** : a per-org **encrypted `key → value` store** ("environment variables") that lets automations + future integration modules reach external systems securely. **Crypto**: generalized the TOTP AES-256-GCM helper into a shared [`@monark/common/crypto`](monark/app/packages/common/src/crypto.ts) (`encrypt`/`decrypt`/`loadEncryptionKey`, key passed in) ; `@monark/auth` now delegates to it (no behavior change). Values are encrypted at rest keyed by a **separate** `SECRETS_ENCRYPTION_KEY` (loaded lazily / fail-closed) so its blast radius is independent of TOTP. **Write-only by design**: the plaintext never crosses tRPC — there is **no read-value procedure at all** ; `secrets.adminList` returns names + metadata, `adminSet` (create, or update value/description) and `adminDelete` are the only writes, all gated by `secrets.{read,manage}` and emitting `secrets.{created,updated,deleted}` (org + key, **never the value**).
