- 2026-09-08: Tooling — `pnpm agent push --force` works, and the push path finally has tests. A forced push could never succeed: [.claude/agentkit/lib/identity.mjs](.claude/agentkit/lib/identity.mjs) passed a bare `--force-with-lease`, which takes its expected value from the remote-tracking ref of a _named_ remote, while the push itself goes to an anonymous `https://x-access-token:…@host/repo.git` so that no credential helper can substitute the operator's cached login. With no remote to derive from, git recorded no expectation and rejected every forced push with `(stale info)` ; even a plain fast-forward. The lease is now passed explicitly as `--force-with-lease=refs/heads/<branch>:<sha>`, taking the expectation from the `refs/remotes/origin/<branch>` this worktree last fetched. That is the same value the bare form would have used, so a concurrent push still correctly fails ; the expectation is deliberately _not_ refreshed first, since fetching immediately before a forced push folds someone else's new commits into the value being authorised and defeats the point of a lease. Fixing only that would have worked exactly once: pushing to an ad-hoc URL does not move `refs/remotes/origin/*` (git maintains those only for a configured remote), so our own successful push left the tracking ref stale and the next forced push failed with the identical `(stale info)`. The push path now records the commit it just pushed — never whatever the remote holds afterwards, which would be a silent fetch of another agent's work. Where no lease can be computed at all, a branch already on the remote is refused with instructions rather than forced blindly, and a branch not yet on it is simply created. Regression cover lands in [tools/tests/agentkit-push.test.ts](tools/tests/agentkit-push.test.ts) (run by `pnpm test:tools`, already wired into CI's repo-checks): the argv construction is pure and pinned, and the git behaviours the fix depends on are pinned against a local bare repository with no network, including the property that must survive every future change — the lease still refuses to clobber a concurrent push. `.claude/agentkit/` had no test of any kind before this, having shipped two bugs in one day.
