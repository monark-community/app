- 2026-05-04: Admin user management — write paths (slice 3 of the admin view). Three new tRPC mutations on the users router : `users.adminUpdateProfile` (admin variant of the self-service profile update ; mirrors the input shape but takes an explicit target `userId`, re-uses the `user.profile-updated` event), `users.adminRequestDeletion` (admin triggers the standard 14-day grace-window flow on a user's behalf, blocks self-targeting since admins delete themselves through `/account`), `users.adminCancelDeletion` (admin cancels a pending grace-window deletion on a user's behalf). Plus one mutation on the auth router : `auth.adminHardDeleteUser` (immediate hard-delete that bypasses the grace window — anonymizes the row + removes the Supabase auth user + emits `user.deleted` in one shot ; lives on auth because Supabase admin teardown is auth's domain ; blocks self-targeting). All four gated by an in-router admin check that calls `adminAssignmentSummary` from `@monark/rbac/server`. UI lives entirely on [/admin/users/[id]](<monark/app/services/web/src/app/(authed)/admin/users/[id]/user-detail.tsx>) : new [admin-profile-form.tsx](<monark/app/services/web/src/app/(authed)/admin/users/[id]/admin-profile-form.tsx>) (banner, avatar, displayName, bio, locale — onBlur-saved like the self-service section) and [admin-danger-zone.tsx](<monark/app/services/web/src/app/(authed)/admin/users/[id]/admin-danger-zone.tsx>) (request-deletion confirmation dialog, cancel-deletion when in grace, hard-delete with typed-email confirmation matching the self-service dialog UX). Avatar/banner uploads route through new admin server actions [admin-actions.ts](<monark/app/services/web/src/app/(authed)/admin/users/admin-actions.ts>) — same sharp pipeline as the self-service uploads but the file lands under the _target_ user's storage folder. Profile form auto-disables when the user is in deletion grace (read-only, mirroring the self-service /account lock-down). **i18n** (en + fr) : `admin.users.profileForm.*` + `admin.users.dangerZone.*` (request + cancel + hard-delete copy, error toasts, dialog strings).
