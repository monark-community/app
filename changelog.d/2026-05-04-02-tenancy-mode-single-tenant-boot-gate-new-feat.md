- 2026-05-04: Tenancy mode + single-tenant boot gate. New feature flag `tenancy.multi-tenant` in [@monark/feature-flags](monark/app/packages/feature-flags/src/contracts/flags.ts) ; defaults OFF, so a fresh deploy is single-tenant unless explicitly flipped. Single-tenant means : exactly one organization is expected, every route gates to a new `/setup` page until that organization exists, and the admin UX collapses around the single-org assumption. New helpers `getBootstrapStatus()` + `bootstrapSingletonOrganization()` + `getSingletonOrganization()` in [@monark/organizations/server](monark/app/packages/organizations/src/server/bootstrap.ts) ; new public tRPC query `organizations.bootstrapStatus` returning `{ mode, bootstrapped, organizationCount }`. New [/setup](monark/app/services/web/src/app/setup/page.tsx) page : status checklist (services / auth / tenancy) that polls every 5s and auto-redirects to home when the system finishes bootstrapping ; "stuck on org" guidance documents the env-var contract verbatim. Bootstrap gate added to both [(anon)/layout.tsx](<monark/app/services/web/src/app/(anon)/layout.tsx>) and [(authed)/layout.tsx](<monark/app/services/web/src/app/(authed)/layout.tsx>) via shared [isSystemBootstrapped()](monark/app/services/web/src/lib/bootstrap-gate.ts) helper ; runs _before_ the session check so even sign-in / sign-up surfaces redirect to /setup pre-bootstrap. /setup itself lives outside both groups so the redirect doesn't loop. Bootstrap-from-env hook on API service boot ([services/api/src/server.ts](monark/app/services/api/src/server.ts)) reads `INITIAL_ORG_SLUG` / `INITIAL_ORG_NAME` / `INITIAL_ORG_PRIMARY_COLOR` env vars (validated by zod in [lib/env.ts](monark/app/services/api/src/lib/env.ts)) and provisions the singleton organization when missing ; idempotent so a restart on a healthy install is a no-op, attribution lands on `actorId: "system:bootstrap"`. Single-tenant UX : [/admin/organizations](<monark/app/services/web/src/app/(authed)/admin/organizations/page.tsx>) fast-redirects to the singleton's edit page when mode is single + count is 1 (the list view stays reachable directly via URL for inspection).
