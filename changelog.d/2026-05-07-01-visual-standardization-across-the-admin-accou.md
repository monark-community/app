- 2026-05-07: Visual standardization across the admin + account detail surfaces. The webhook detail page's "card-less" feel is now the canonical pattern : page-level `h1` + subtitle, sections rendered as `h2` with `<Separator />` between them, no `<Card>` wrappers around section content.
  - **Shared `<PageSection>` primitive** ([services/web/src/components/page-section.tsx](monark/app/services/web/src/components/page-section.tsx)). Renders a real `<h2>` (Card components emitted `<div>`s, breaking screen-reader hierarchy) + optional subtitle + header-row action slot + a `tone` variant (`default` / `danger` / `warning`) for color-accented sections like Danger Zone. Replaces ~12 ad-hoc `<Card className="bg-transparent shadow-none">` instances across the admin + account surfaces.
  - **Shared `<AccountPageHeader>`** ([services/web/src/app/(authed)/account/account-page-header.tsx](<monark/app/services/web/src/app/(authed)/account/account-page-header.tsx>)). Renders the page-level `h1` + subtitle for `/account/{profile,security,notifications,danger}`, sourcing the title from `account.tabs.<tab>` (matches the sidebar) and the subtitle from new `account.subtitles.<tab>` keys. Tone variant pins the title color for Danger Zone.
  - **Refactored pages** :
    - `/admin/webhooks/[id]` ([webhook-editor.tsx](<monark/app/services/web/src/app/(authed)/admin/webhooks/webhook-editor.tsx>)) — split into "Endpoint" (URL / scope / description / status) + "Event subscriptions" PageSections with separators ; the action footer becomes its own delimited row. The user pointed to this layout as the reference look.
    - `/admin/rbac/roles/[id]` ([role-editor.tsx](<monark/app/services/web/src/app/(authed)/admin/rbac/role-editor.tsx>)) — replaced the `rounded-lg border` identity grid + permission-block borders with PageSections "Identity" + "Permissions". The lock badge for built-in ADMIN moves into the PageSection's action slot.
    - `/admin/users/[id]` ([user-detail.tsx](<monark/app/services/web/src/app/(authed)/admin/users/[id]/user-detail.tsx>) + 5 sub-components) — Profile, Identity, Roles, Account actions, Notifications, Danger zone subsections all converted to PageSections with separators between them. Danger zone uses `tone="danger"`.
    - `/admin/organizations/[id]` ([organization-detail.tsx](<monark/app/services/web/src/app/(authed)/admin/organizations/[id]/organization-detail.tsx>)) — single PageSection ; loading + error states drop their Card wrappers for a flat skeleton row.
    - `/account/profile` — page renders the AccountPageHeader (h1) ; ProfileSection drops its own Card and renders content directly under the page header (single block, no extra h2 needed for one section).
    - `/account/security` — page renders AccountPageHeader (h1) ; the four sub-sections (Email, Password, TOTP, Trusted devices) each become a PageSection with a `<Separator />` between them. Heading hierarchy is h1 → h2 × 4.
    - `/account/notifications` — same shape : AccountPageHeader + a single PageSection.
    - `/account/danger` — AccountPageHeader with `tone="danger"` ; the "grace period" + the deletion-not-yet-pending paths both render through PageSection (the former with `tone="warning"`, the latter with `tone="danger"`).
  - **i18n.** Added `account.subtitles.{profile,security,notifications,danger}` (en + fr), `admin.webhooks.editor.{endpointSectionTitle,endpointSectionSubtitle,subsSectionSubtitle}`, `admin.rbac.editor.{identitySectionTitle,identitySectionSubtitle,permissionsSectionSubtitle}`. Existing `account.{profile,email,password,totp,trustedDevices,notifications,danger}.title/subtitle` keys are reused as section h2 + subtitle copy.
  - **Net effect.** Every admin + account detail page now follows the same pattern : one h1 page header + N PageSections separated by `<Separator />` rules. No more bordered card boxes around every settings group ; heading-hierarchy is correct for screen readers + visual scanning. `pnpm typecheck` clean across all 15 packages.
