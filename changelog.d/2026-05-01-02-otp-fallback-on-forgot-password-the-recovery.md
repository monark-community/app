- 2026-05-01: OTP fallback on `/forgot-password`. The recovery email already carried a 6-digit code as a fallback for the link, but there was nowhere to enter it ; the post-submit view on [/forgot-password](<monark/app/services/web/src/app/(anon)/forgot-password/forgot-password-form.tsx>) now mirrors the [signup check-email](<monark/app/services/web/src/app/(anon)/signup/check-email/check-email-actions.tsx>) pattern with an `<InputOTP>` 6-digit input, a "verify + continue" button, and a resend-email action.
