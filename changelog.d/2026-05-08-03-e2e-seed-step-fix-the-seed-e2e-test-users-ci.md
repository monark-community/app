- 2026-05-08: e2e seed step fix. The `Seed e2e test users` CI step started failing with `ERR_MODULE_NOT_FOUND: Cannot find package '@monark/auth'` after a recent dep cleanup. Root cause : `tools/seed-e2e-users.ts` imports `@monark/auth/server` and `@monark/organizations/server` (alongside `@monark/db` and `@monark/rbac`), but the workspace root [`package.json`](monark/app/package.json) only listed `@monark/db` and `@monark/rbac` as direct deps. pnpm's isolated layout only surfaces direct deps at the workspace root's `node_modules/`, so `tsx` couldn't resolve the missing two — locally the script may have worked because of stale linking from earlier installs, but `pnpm install --frozen-lockfile` on CI gave it a clean tree where the resolution failed. Added both missing packages as `workspace:*` direct deps. The seed step now resolves cleanly on the next CI run.
