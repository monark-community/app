- 2026-07-04: Filter menu — searchable option lists. A field's value submenu in [`FilterMenu`](monark/app/services/web/src/components/patterns/filter-menu.tsx) now shows a search box at the top once its option list is long enough (> 8 options, or forced via a new per-filter `searchable?` flag), on both the desktop dropdown (sticky search, filtered radio / checkbox list) and the mobile modal section. Matching is case-insensitive against each option's label (or an explicit `searchText` when the label is a non-string node), with a "no results" empty state. Keeps the long taxonomy pickers (e.g. the projects Industries filter) usable without scrolling. New optional `searchPlaceholder` / `noResults` on `FilterMenuLabels` (text-free component ; both data callers pass the shared `filters.*` strings), new `filters.searchPlaceholder` + `filters.noResults` i18n keys in en + fr. `tsc --noEmit` + `eslint` green.
