- 2026-08-04: Chat — **token streaming** for the assistant's replies over a dedicated **`POST /chat/stream`** Server-Sent Events endpoint ([server.ts](monark/app/services/api/src/server.ts)), so answers type out live instead of appearing all at once. Not tRPC (the web client is httpBatch-only) — the endpoint authenticates with the same Supabase bearer and calls the shared `sendMessage(ctx, input, hooks)` (extracted from the `chat.messages.send` mutation, now used by both) with an `onTextDelta` hook that emits `token` frames, ending with `done` / `error`. The web thread consumes it via [stream.ts](monark/app/services/web/src/components/chat/stream.ts) (fetch + ReadableStream, so the bearer header works), appending tokens to a live bubble and refetching on completion. `confirm`/`reject` stay non-streamed for now. `tsc` (chat + api + web) + `eslint` green ; chat's 3 unit + 12 integration tests still pass.
