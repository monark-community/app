- 2026-05-08: Codecov upload fix. The first CI run after the merge-coverage infra landed showed Codecov reporting numbers nobody recognised ; the upload log surfaced two compounding bugs.
  - **`files: |` block was passed as one giant filename.** [`.github/workflows/ci.yml`](monark/app/.github/workflows/ci.yml) used a YAML literal-block scalar to list each per-package lcov path on its own line. codecov-action v4 takes the YAML value verbatim and forwards it as a single CLI arg, so the action received `-f "./packages/auth/coverage/lcov.info\n./packages/branding/..."` (literal `\n` characters embedded). The `not_found_files` warning in the action log shows the entire block as a single missing path. Switched to comma-separated single-line syntax which the v4 uploader splits correctly.
  - **Auto-discovery uploaded 58 conflicting files.** With the explicit `files:` list silently doing nothing, codecov-action v4 fell back to walking the workspace for every `lcov.info` and `coverage-final.json` it could find. With our split coverage layout (`coverage/unit/`, `coverage/integration/`, plus the merged `coverage/`) that meant **three lcov files per package** describing the same source paths with different totals, plus the matching `coverage-final.json` triplets. Codecov's per-source merge logic ended up reporting whichever file won the deduplication race rather than the merged number we intended. Two fixes : (1) `disable_search: true` on the action so only the explicit `files:` list gets uploaded ; (2) `tools/merge-coverage.ts` now `rm -rf coverage/{unit,integration}/` after producing the merged output, so even if `disable_search` is ever flipped back the upload stays clean. Also added the previously-missing `packages/webhooks` and `services/web` paths to the upload list.
  - **Net effect.** Codecov uploads exactly the merged `lcov.info` per package starting on the next CI run ; the dashboard number will reflect the actual measured baseline (matching what `pnpm coverage:merge` prints locally) instead of whichever per-run lcov happened to land last in Codecov's merge.
