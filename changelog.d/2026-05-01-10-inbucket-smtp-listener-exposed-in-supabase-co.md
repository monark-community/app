- 2026-05-01: Inbucket SMTP listener exposed in [supabase/config.toml](monark/app/supabase/config.toml) (`smtp_port = 54325`). Without this, the dev mail server only had a web UI on 54324 and SMTP delivery silently failed ; account-security emails (new device, password change, revoke-all) never reached the inbox. The auth README's SMTP_URL example updated to `smtp://127.0.0.1:54325` ; the previous `localhost:1025` value matched Mailpit, not Inbucket. Run `pnpm dev:tools mail` to inspect captured mail.
