- 2026-09-08: Fixed the two-factor onboarding prompt reopening after it was dismissed. [`TotpOnboardingPrompt`](services/web/src/components/totp-onboarding-prompt.tsx) gated visibility on `query && !localState`, and because it mounts in the [(authed) layout](<../services/web/src/app/(authed)/layout.tsx>), any client-side navigation remounted it with the local flag back at its initial value while the query cache still said `shouldPrompt: true` — the invalidated refetch hadn't landed yet. Visibility now comes from the cache alone, written synchronously on dismiss so it survives a remount, with the persisted mutation behind it and an invalidate on failure so a decision that never reached the database isn't treated as made. Covered by a component test that dismisses, unmounts and remounts.
