- 2026-07-04: Global search — app-wide ⌘K command palette. Added a command palette reachable from anywhere via ⌘K / Ctrl+K or a search-field-shaped trigger at the top of the primary-nav drawer ([global-search/](monark/app/services/web/src/components/global-search/)). `GlobalSearchProvider` (mounted in the [(authed) layout](<monark/app/services/web/src/app/(authed)/layout.tsx>)) owns the open state + the single global keydown handler and renders the dialog once for the whole authed tree ; `GlobalSearchTrigger` (in [primary-nav-menu.tsx](monark/app/services/web/src/components/primary-nav-menu.tsx)) opens it via context and shows a platform-aware Kbd (⌘ on Apple, Ctrl elsewhere). Results are two cmdk groups (built on the existing [`ui/command`](monark/app/services/web/src/components/ui/command.tsx), extended with `shouldFilter` / `label` pass-through) : (1) **contextual** — the current section's entities live from the api (`projects.list` search on `/data/projects`, client-filtered `industries.list` on `/data/industries`, `calendar.events.search` on `/calendar`), each navigating to its detail deep-link ; (2) **navigation** — a "Go to" list of app sections (admin routes gated on `rbac.isAdmin`) filtered by the query. cmdk's built-in filtering is off since results are already filtered server-side / here. The calendar's own local ⌘K binding was removed so it no longer double-fires with the global one ([calendar-shell.tsx](<monark/app/services/web/src/app/(authed)/calendar/calendar-shell.tsx>)) ; its toolbar Search button + `CalendarSearch` popover stay as a page-scoped affordance. New `globalSearch.*` i18n (trigger, placeholder, group + route labels) in en + fr. `tsc --noEmit`, `eslint`, and the 222-test suite green.
