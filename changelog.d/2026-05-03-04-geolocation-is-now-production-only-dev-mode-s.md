- 2026-05-03: Geolocation is now production-only ; dev mode skips IP + country capture entirely. [`recognizeDeviceAfterAuth`](monark/app/services/web/src/lib/trusted-device-cookie.ts) used to read `x-forwarded-for` + the four edge-geo headers (Vercel / Cloudflare / CloudFront / generic) regardless of environment ; in dev that produced a phone-LAN IP we couldn't translate to anything useful + a null country, so the row stored noise. Now both fields are forced null in dev ; the trusted-device card already gated its "Local development" fallback on `NODE_ENV !== "production" + null IP + null country`, so the visual reads correctly without changes there. UA-CH client hints are still captured in dev (useful for testing the Pixel 7 / Galaxy / iPad model-detection path locally).
