The project and industry forms are now split into three `PageSection`s instead of one. **Attributes** holds the reorderable structured fields (for projects, still ordered by the table's configured column order via `fieldOrder`, description excluded since it was never a column) ([project-form.tsx](<monark/app/services/web/src/app/(authed)/data/projects/project-form.tsx>), [industries-list.tsx](<monark/app/services/web/src/app/(authed)/data/industries/industries-list.tsx>)). **Description** is now the main-content section backed by the shared TipTap [`RichTextEditor`](monark/app/services/web/src/components/fields/inputs/rich-text-editor.tsx) WYSIWYG (the project description moves from a plain `Textarea` to rich text ; the industry form already used it) — the editor's programmatic `setContent` doesn't emit, so loading an existing record doesn't false-trigger the dirty bar. **Discussion** is a new reusable, presentational [`DiscussionSection`](monark/app/services/web/src/components/patterns/discussion-section.tsx) : a comment composer over a flat, thread-less comment list, text-free (takes translated `labels` + `comments`), wired for now to a static two-comment preview via `useDiscussionPreview` with a disabled composer — swap `comments` for real data when the feature lands. The project form gained a full-page `<h1>` (shown only when `containment === "viewport"`, since the panel's `PanelHeader` already carries the record title). New shared `dataForm` i18n namespace (section titles + the discussion preview strings, en + fr) ; the project `descriptionHelp` copy updated from "Markdown" to rich text.
