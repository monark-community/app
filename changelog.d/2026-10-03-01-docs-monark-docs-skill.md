- 2026-10-03: Docs — **a `monark-docs` skill, and the published docs start moving to a reader-first structure**. An audit of the docs site found its shape came from a mechanical split (PR #76 cut every long guide at its `##` headings, leaving 61 fragment pages such as "Not yet / deferred" and "The 2x2"), categories that mirror the codebase (screens, packages, a "Modules" tab for extended modules) rather than readers' jobs, no starting point or running order, and pages that describe screens instead of saying what to do. The new skill at [.claude/skills/monark-docs/SKILL.md](.claude/skills/monark-docs/SKILL.md) defines eight sections (`get-started`, `use`, `administer`, `build`, `reference`, `concepts`, `operate`, `decisions`), seven page types with templates and word budgets, a cutting-pass style guide with before/after examples from our own docs, an audit procedure, a migration map for every existing folder, and a dependency-free linter ([docs-lint.mjs](.claude/skills/monark-docs/scripts/docs-lint.mjs)) that checks page type, budget, user-page jargon, house punctuation and storyline wiring. It supersedes [docs/agents/user-doc.md](docs/agents/user-doc.md). As the pilot, the Data user guide is rewritten as task pages under [docs/use/data/](docs/use/data/_index.md) with a new [query syntax reference](docs/reference/query-syntax.md), and the Kanban guide as [packages/kanban/docs/use/](packages/kanban/docs/use/_index.md) ; the rewrite also fixes drift from the UI (saved views exist only with the query bar, which replaces the Filters menu rather than toggling with it ; "WIP limit" is **Card limit** ; restoring a deleted record is not admin-only : anyone who can edit the model's records restores it from the row menu). [notify-docs.yml](.github/workflows/notify-docs.yml) now fires for the new section folders ; the docs site needs the matching sync mappings before they render.
