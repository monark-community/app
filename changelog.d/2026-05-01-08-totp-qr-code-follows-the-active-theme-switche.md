- 2026-05-01: TOTP QR code follows the active theme. Switched [`beginTotpEnrollment`](monark/app/packages/auth/src/server/totp.ts) from `qrcode.toDataURL` (PNG) to `qrcode.toString({type: "svg"})` ; the SVG is post-processed to replace the dark hex with `currentColor` and the background is left transparent (via `light: "#00000000"`). Response shape changed: `{ secret, qrSvg }` instead of `{ secret, qrDataUrl }`. Both consumers ([account/totp-section.tsx](<monark/app/services/web/src/app/(authed)/account/totp-section.tsx>) + [dev-overlay/panels/totp.tsx](monark/app/services/web/src/components/dev-overlay/panels/totp.tsx)) now render the SVG inline via `dangerouslySetInnerHTML` inside a `text-foreground` wrapper, so the QR is black on light themes and white on dark with no `<img>` filter trick or hardcoded white background. The data URL the server returned was always trusted (no untrusted input is interpolated).
