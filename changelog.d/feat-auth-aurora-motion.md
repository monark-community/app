- 2026-09-08: Made the auth-page aurora backdrop read as moving. The blobs in [globals.css](services/web/src/app/globals.css) drifted over 26-38s along a single straight vector, which at that speed and distance registered as a static gradient. Cycles are now 14-23s with roughly double the travel and a wider scale range, and each keyframe set gained a midpoint that sits off the start-to-end vector — with `alternate`, a two-stop animation is a straight shuttle, so the waypoint is what turns the round trip into a drift rather than a slide. Durations stay mutually non-multiple so the three blobs don't visibly sync into a pulse. Motion remains transform-only (`translate3d` + `scale`) so it composites on the GPU instead of repainting, and `prefers-reduced-motion: reduce` still drops the drift while keeping the composition.
