- 2026-08-10: Data models — **public boards** (the read side of public forms). A public form can now also expose a **moderated, searchable, read-only list** of its entries — turning a Data Model into a feature-request / bug / Q&A board. Submissions become a `DataFormEntry` (`PENDING`) invisible to the public until an admin **approves** them ([base.prisma](monark/app/packages/db/prisma/base.prisma) `DataFormEntry` + `DataFormEntryStatus`, migration [20260810175306](monark/app/packages/db/prisma/migrations/20260810175306_data_form_boards/migration.sql)). A board carries its own **read** allow-list `DataForm.listReadFieldKeys` — SEPARATE from the writable `fieldKeys` — so a `status` field is publicly _readable_ but not publicly _writable_; the public read procedures return records **projected** to that list ([forms.ts](monark/app/packages/data-models/src/server/forms.ts) `projectPublicRecord`), so the raw `DataRecord.data` (private fields, submitter email) never leaves the server. Board search + pagination reuse the record engine via a new `publishedForFormId` relation-filter on `listDataRecords`. New procedures: admin `forms.entries.{pending,publish,reject}` (moderation queue) and anonymous `forms.public.{list,record}` (read-access gated per form by `listPublicRead` — anyone-with-the-link vs invite-key — and rate-limited); `data-models.form-entry-published` event on approval. Web: a **Public board** block + a Pending-review moderation panel in the model editor ([sharing-section.tsx](<monark/app/services/web/src/app/(authed)/admin/data-models/[id]/sharing-section.tsx>)), and the public `/f/[token]` page becomes a searchable board with a "New entry" action and linkable per-entry detail at [/f/[token]/e/[recordId]](monark/app/services/web/src/app/f/[token]/e/[recordId]/page.tsx) (submitted rich-text is tag-stripped before public display). i18n en+fr. 3 new board integration specs (pending hidden then published, projection strips non-read fields incl. an admin-set-later field flowing through, title search); full data-models suite 114 green; `gen` + `tsc` + `lint` + `check:tiers`/`check:modules`/`check:mcp`/`check:i18n` (2320 keys) green.
