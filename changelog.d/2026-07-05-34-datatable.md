- 2026-07-05: DataTable — sort-priority number in column headers. When two or more sorts are stacked, a sorted column's header arrow carries its 1-based position in the priority list (`↑1`, `↓2`, …, from `column.getSortIndex()` in [data-table.tsx](monark/app/services/web/src/components/patterns/data-table/data-table.tsx)), so "sorted by Status, then Budget" reads directly off the headers instead of only inside the Sorting editor ; a lone sort shows just the arrow. Verified via the `table-sorting-active` screenshot story ; `tsc` + `eslint` green.
