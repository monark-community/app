- 2026-05-04: Admin organizations CRUD (slice 5 of the admin view). Three new admin-gated tRPC procedures on the organizations router : `organizations.adminList` (cursor-paginated, search by displayName or slug, soft-deleted orgs filtered out), `organizations.adminGet({ id })`, and `organizations.adminUpdate({ id, displayName?, slug?, logoUrl?, primaryColor? })`. Slug rotations record an `OrgSlugRedirect` row with a 90-day expiry inside the same transaction so in-flight links don't 404 ; slug-collision throws `ValidationError` cleanly instead of a Prisma constraint error. Hex-color (`#RGB` / `#RRGGBB`) and slug (`[a-z0-9-]`, 2–60 chars) zod validators added at the procedure boundary. New `organization.updated` event with `changed` array + optional `previousSlug` + actor id ; subscribers can branch on which fields rotated. `@monark/organizations` now has `@monark/rbac` + `zod` in its workspace deps. UI : [/admin/organizations](<monark/app/services/web/src/app/(authed)/admin/organizations/page.tsx>) renders a debounced search + paginated card list (logo, displayName, slug, primary-color swatch) ; [/admin/organizations/[id]](<monark/app/services/web/src/app/(authed)/admin/organizations/[id]/page.tsx>) is a single-card edit surface for displayName / slug / primary color / logo upload (onBlur-saved, slug + color get inline regex validation with toast feedback on bad input). Logo uploads route through new admin server action [adminUploadOrgLogoAction](<monark/app/services/web/src/app/(authed)/admin/organizations/actions.ts>) — same sharp pipeline as user avatars but the file lands at `org-logos/<orgId>/<ts>.webp` in the shared `avatars` Storage bucket. **i18n** (en + fr) : `admin.organizations.{searchLabel, searchPlaceholder, empty, emptySearch, loading, loadMore, detail.*}`.
