- 2026-08-05: GitHub — **new extended module `@monark/github`: GitHub trigger events + read/write action nodes for automations** (flag-gated `github.enabled`, default off). Built on the core `@monark/automation` engine like calendar/kanban (extended→core only; `check:tiers` clean), no new tables — the only per-org state (the inbound webhook signing secret) lives in the `@monark/secrets` substrate. **Triggers:** an inbound `POST /hooks/github/:org` ([server.ts](monark/app/services/api/src/server.ts), raw body captured via `express.json({ verify })`) verifies GitHub's `X-Hub-Signature-256` HMAC against the org's stored secret, maps the delivery, and `emit()`s one of seven `github.*` domain events ([events.ts](monark/app/packages/github/src/contracts/events.ts) + [webhook.ts](monark/app/packages/github/src/server/webhook.ts)) — issue opened, issue/PR commented, PR opened, PR merged, PR review submitted, push, release published. They join the `DomainEvent` union (`pnpm gen:events`) and register with descriptions + `{{ trigger.* }}` field metadata ([event-types.ts](monark/app/packages/github/src/server/event-types.ts)), so the automation subscriber fires matching flows automatically and they show in the trigger + webhook-subscription pickers. **Actions:** 11 nodes registered under the `github` namespace ([nodes/](monark/app/packages/github/src/server/nodes)) — create/get/list issues, comment, add labels, set issue state, create/get PR, request review, list commits, search issues/PRs — each resolving its token from an org secret (`ctx.getSecret`) and calling the REST API through the shared SSRF-guarded `safeFetch` ([client.ts](monark/app/packages/github/src/server/client.ts)), with declared `outputFields` for the variable picker. **Connection UI:** a flag-gated `/github` settings page ([github-settings.tsx](<monark/app/services/web/src/app/(authed)/github/github-settings.tsx>)) to generate/rotate the webhook secret (shown once), copy the webhook URL, and see setup steps, backed by `github.connection.{status,generateWebhookSecret,disconnect}` (gated on a new `github.manage` permission); plus a `PRIMARY_NAV` entry (git-pull-request icon, since lucide dropped its brand `Github` glyph). Wired all `register*` at api boot. Tests: 10 unit (`mapGithubEvent` mapping for every event + `parseRepoRef`) + 2 integration (connection RBAC deny + connect→status→disconnect round-trip). `pnpm gen` + `typecheck` (github/api/web) + `lint` + `check:tiers`/`check:modules`/`check:i18n` (2115 keys) all green. Auth is a token-via-secrets MVP; a GitHub App is a future upgrade that wouldn't touch the nodes.
