- 2026-09-08: Tooling — **the published documentation now syncs to its own site repository**. The user guide, each extended module's user guide, and the technical documentation are rendered at [monark-community/app-docs](https://github.com/monark-community/app-docs) ; that repo owns the presentation, this one stays the source of truth for the prose. [notify-docs.yml](.github/workflows/notify-docs.yml) is this side of the seam: a push to `develop` touching `docs/user-guide/**`, `docs/technical-documentation/**`, or `packages/*/docs/**` fires a `repository_dispatch` at the site, which converts the Markdown to MDX and opens a PR against itself when the result differs. The dispatch is deliberately an optimisation rather than a dependency ; the site also syncs on a daily schedule, so a missing or lapsed credential delays the docs instead of breaking them, and the workflow skips itself with a notice rather than failing when its secrets aren't set. Auth is a GitHub App token scoped to `app-docs` alone (`DOCS_SYNC_APP_ID` / `DOCS_SYNC_APP_PRIVATE_KEY`), the same reasoning as the [changelog workflow](.github/workflows/changelog-compile.yml): `GITHUB_TOKEN` is scoped to this repository and can't reach another one. Documented under "Publishing the docs" in [ci.md](docs/technical-documentation/ci.md).
