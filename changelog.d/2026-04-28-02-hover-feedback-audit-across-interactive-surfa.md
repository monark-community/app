- 2026-04-28: Hover-feedback audit across interactive surfaces. The /account vertical tabs had no hover state because the base `TabsTrigger` only carried an active-state rule ; the cursor-pointer pass surfaced this when buttons stopped looking dead but tabs still did. **Base `TabsTrigger`** (registry + [services/web/src/components/ui/tabs.tsx](monark/app/services/web/src/components/ui/tabs.tsx)) now carries `hover:bg-muted/60 hover:text-foreground`. The 60% opacity is deliberate so consumers that override the active state to the same `bg-muted` (the AccountShell's vertical tabs, by spec) still keep a clear delta between "hovered" and "active" ; the active rule wins on the active row via data-attribute specificity, so nothing else has to change. **Inbox filter buttons** ([inbox.tsx](monark/app/services/web/src/app/account/notifications/inbox.tsx)) now use the same `hover:bg-muted/60 hover:text-foreground` pattern on inactive states, with `transition-colors` for smoothness. **NotificationsSection toggle** ([notifications-section.tsx](monark/app/services/web/src/app/account/notifications-section.tsx)) gained per-state hover (`bg-primary` → `hover:bg-primary/85`, `bg-muted` → `hover:bg-muted/70`), conditionally attached so the disabled / forced state has zero hover delta — disabled toggles shouldn't pretend to be interactive. **Audit confirmed already-good**: `Button` variants (`hover:bg-primary/90` etc.), `AccordionTrigger` (`hover:underline`), `Toggle`, `SidebarMenuButton`, `dropdown-menu` / `context-menu` / `menubar` / `select` / `command` items (Radix maps hover to `data-[highlighted]` / focus, and the items already have `focus:bg-accent`), `NotificationsBell` button + popover rows, `CollapsibleSection` header, profile avatar pencil overlay (`group-hover:bg-black/45`), inline link-style buttons (sign-out, TOTP cancel, mark-read, dismiss). **Audit deliberately skipped**: `Switch` (state-color flip + thumb position is the feedback ; an extra hover bg is noisy), `Checkbox` / `RadioGroup` (small targets ; the click-target's `<label>` is the hover surface in practice), `<a>` anchors (browser handles).
