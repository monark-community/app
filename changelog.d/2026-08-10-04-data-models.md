- 2026-08-10: Data models — **public forms** (flag `data-models.public-forms`). Admins can publish a form for a Data Model so people who aren't users can submit records — either **anonymously** via a shareable `/f/<token>` link, or by **email invite** (each recipient gets a unique, single-use, SHA-256-hashed key). A form exposes only a chosen **subset of fields** (`DataForm.fieldKeys`); everything else (e.g. an admin-maintained `status`) stays private — never shown to or writable by the public. New core tables `DataForm` + `DataFormInvite` ([base.prisma](monark/app/packages/db/prisma/base.prisma), migration [20260810145830](monark/app/packages/db/prisma/migrations/20260810145830_data_public_forms/migration.sql)); data layer [forms.ts](monark/app/packages/data-models/src/server/forms.ts) + a `forms` sub-router ([router.ts](monark/app/packages/data-models/src/server/router.ts)) whose `public.{get,submit}` procedures authorize from the **token, never the session** (resolving org + model from the form row, since anonymous requests have no `ctx`/org). Submissions validate against ONLY the exposed fields (`recordDataSchema(publicFields)`, which strips any injected private key), default the rest, auto-generate the reserved `title` when it isn't exposed, and write through the normal `createDataRecord` with a sentinel `createdBy`; a form-save rule requires every required field (except `title`) to be on the form so a submission can't fail on a missing private value. Only simple field types are exposable (`PUBLIC_FORM_FIELD_TYPES`; no relation/file/document/formula). Anonymous submits are per-IP rate-limited (`checkRateLimit`; added `clientIp` to the tRPC context); email invites mail a link via `sendMail` and lock after one submission. New `data-models.manage-forms` permission, `data-models.form-submitted` event (the submit path also emits `record-created`, so watchers/automation/webhooks keep working), a **Sharing** section in the model editor ([sharing-section.tsx](<monark/app/services/web/src/app/(authed)/admin/data-models/[id]/sharing-section.tsx>)), and a public route at [/f/[token]](monark/app/services/web/src/app/f/[token]/page.tsx) (outside the auth gate, reusing the `AutoForm` field toolkit). i18n en+fr (`admin.dataModels.editor.sharing.*`, `public.form.*`). 8 new integration specs (subset-strip privacy, required-field rule, single-use invites, auto-title, org-scoped token lookup); `gen` + `tsc` + `lint` + `check:tiers`/`check:modules`/`check:mcp`/`check:i18n` (2300 keys, en/fr parity) all green.
