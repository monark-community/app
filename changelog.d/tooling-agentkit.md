- 2026-09-08: Tooling — agentkit, the parallel-agent workspace layer: reserved dev ports per worktree, a policy guard that makes unattended runs possible, and mechanically enforced machine-account identity. Every checkout (the primary one and each worktree) now owns a numbered **port slot** recorded in a registry that lives above all worktrees, so slot N means web `3000 + N*10` and api `4000 + N*10` and two sessions can never be handed the same socket ; the slot is reserved by a `SessionStart` hook and written into that worktree's own `.env` files, so `pnpm dev` picks it up with no flags (`services/web/dev.mjs` replaces the hardcoded `--port 3000`). A `PreToolUse` guard ([.claude/agentkit/policy.json](.claude/agentkit/policy.json)) answers permission requests from an enumerated denylist of irreversible and identity-relevant operations instead of prompting, with a third `ask` tier that becomes an immediate refusal-with-reason once `pnpm agent night on` is set, so an overnight `/loop /overnight` run can never stall on a dialog. Identity is no longer convention: `pnpm agent wt new` sets the `monark-agent` identity in the worktree, `git commit` with any other identity is refused, bare `git push` is blocked, and `pnpm agent pr` is the only push path — HTTPS with `MONARK_AGENT_TOKEN` and `-c credential.helper=` so Git Credential Manager cannot substitute the operator's cached login, then a REST PR so `user.login` is the machine account too. New commands: `pnpm agent {ports,wt,identity,gate,push,pr,night,doctor}` and `/wt`, `/ports`, `/ship`, `/overnight`. See [CLAUDE.md](CLAUDE.md) § Parallel work.
