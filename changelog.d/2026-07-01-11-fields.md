- 2026-07-01: Fields — reusable, descriptor-driven form inputs + table cells. New [`@/components/fields`](monark/app/services/web/src/components/fields) toolkit built for the coming polymorphic Data Model : a single field-type registry ([registry.tsx](monark/app/services/web/src/components/fields/registry.tsx) `FieldInput` + [schema.ts](monark/app/services/web/src/components/fields/schema.ts) + [cells.tsx](monark/app/services/web/src/components/fields/cells.tsx)) drives both a schema-driven [`AutoForm`](monark/app/services/web/src/components/fields/auto-form.tsx) and matching data-table columns via [`fieldColumn`](monark/app/services/web/src/components/fields/field-column.ts). Covers all field kinds (text, long text, rich text / WYSIWYG, number, boolean, date, datetime, single-select, multi-select with optional custom values, relation, url, email) with an RHF input per type ([inputs/\*](monark/app/services/web/src/components/fields/inputs)) wrapped in a shared [`FieldShell`](monark/app/services/web/src/components/fields/field-shell.tsx) that formalizes the copy-pasted label + control + help + error block ; validation flows from zod fragments assembled by `schemaForFields`. Single/multi-select support opt-in colored `badges` and relation supports `avatars` (image or initials). The `richText` field is a headless [Tiptap](https://tiptap.dev) editor ([rich-text-field.tsx](monark/app/services/web/src/components/fields/inputs/rich-text-field.tsx)) storing sanitized HTML, with a [`RichTextView`](monark/app/services/web/src/components/fields/rich-text-view.tsx) DOMPurify-sanitized read-only renderer and scoped `.rich-text-content` styles in [globals.css](monark/app/services/web/src/app/globals.css). Adopts react-hook-form for the app (first use) and ports the shadcn `command` / `form` / `radio-group` primitives into [components/ui](monark/app/services/web/src/components/ui) ; added `react-hook-form`, `@hookform/resolvers`, `cmdk`, `@radix-ui/react-radio-group`, `@tiptap/*`, `dompurify` to [services/web/package.json](monark/app/services/web/package.json). New `fields.*` i18n chrome + validation keys in both locales ; text-free components take already-translated field labels as props. Dev gallery at [(authed)/dev/fields](<monark/app/services/web/src/app/(authed)/dev/fields/page.tsx>) exercises every type in a form and a table ; unit coverage in [tests/lib/fields.test.ts](monark/app/services/web/tests/lib/fields.test.ts). No RBAC / schema / event changes ; the descriptor is designed to map 1:1 onto a server field definition when the polymorphic layer lands.
