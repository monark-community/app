- 2026-04-29: Global app bar across authenticated surfaces. New [`AppBar`](monark/app/services/web/src/components/app-bar.tsx) (server component) — sticky top-0, blurred `bg-background/70` background, subtle border-bottom, `max-w-6xl` content width. Left side carries the Monark logo + wordmark linked to `/account` ; right side carries the existing `NotificationsBell` plus a new [`UserMenu`](monark/app/services/web/src/components/user-menu.tsx) (avatar dropdown). The user menu shows the avatar (or initials over the brand orange→red gradient when no avatar is set, matching profile-section's empty-state pattern) and on click opens a dropdown with the user's display name + email as a non-interactive header, then `Account` (link to `/account`) and `Sign out` (invokes the existing `signOutAction` server action via `useTransition`). The previous per-page headers are gone from `/account`, `/account/notifications`, `/account/delete`, `/admin` — each page now mounts `<AppBar />` once and renders its own `<h1>` inside the content area instead of mixing nav with title. Pre-auth surfaces (signin, signup, /auth/confirm-error, etc.) keep their own centered "logo + form" layout ; the appbar implies "you're inside the app." **i18n** (en + fr): new `appBar.{home, userMenu.{triggerAria, account, signOut, signingOut}}` namespace.
