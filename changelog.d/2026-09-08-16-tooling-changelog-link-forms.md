- 2026-09-08: Tooling — **the changelog-fragment link rule now catches the angle-bracket form too**. `](<../path>)` is what the house style uses for any target containing parentheses, e.g. `](<services/web/src/app/(authed)/layout.tsx>)`, which is exactly where a stray `../` is most likely and hardest to spot ; the original regex in [tools/compile-changelog.ts](tools/compile-changelog.ts) only matched the bare `](../path)` form, so six such links passed every check and reached `develop`. The two forms terminate differently — the angle-bracket one ends at `>` and may contain `)`, which is the whole reason it exists, while the bare one ends at the first `)` and cannot — so [the shared rule](tools/lib/changelog-fragments.ts) matches them as two alternatives rather than one loosened character class. Found while merging #73, whose own fix left those six links in place because it inherited the same blind spot.
