- 2026-09-08: Auth — **otplib upgraded from 12 to 13**, which is a full rewrite rather than a compatible bump. v13 drops the stateful `authenticator` singleton for a functional API, so [packages/auth/src/server/totp.ts](packages/auth/src/server/totp.ts) now calls `generateSecret()`, `generateURI({ issuer, label, secret })` and `verifySync({ secret, token, epochTolerance })` instead of `authenticator.generateSecret()`, `authenticator.keyuri()` and `authenticator.check()`. The clock-skew allowance moved from a global `authenticator.options = { window: 1 }` to a per-call `epochTolerance` in seconds ; at the default 30 sec period `epochTolerance: 30` is the same ±1 step, verified directly against the new package (a code one step out still passes, two steps out is still rejected). Enrolled users are unaffected : v13 generates the same 32-character Base32 secret and the same `otpauth://totp/<issuer>:<label>` URI shape, so existing secrets keep verifying and no re-enrollment or migration is needed. The tolerance now travels with each verification through a small `checkTotpCode` helper rather than living as module-level state, and [packages/auth/tests/integration/totp.test.ts](packages/auth/tests/integration/totp.test.ts) mints codes through a `totpCode()` helper over `generateSync`. Unblocks Dependabot PR #9, which was red on `TS2305: Module '"otplib"' has no exported member 'authenticator'`.
