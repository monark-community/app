- 2026-05-02: Post-sign-in recovery-code reminder modal. New `RecoveryCode.acknowledgedAt` column ([migration 20260502100000](monark/app/packages/db/prisma/migrations/20260502100000_add_recovery_code_acknowledged_at/migration.sql)) tracks whether the user has been shown a "you spent a code" reminder for each used row ; the unack state lives server-side so closing the tab without handling it re-prompts on the next sign-in. New tRPC surface on `auth.totp`: `recoveryStatus` (query: enrolled / hasUnacknowledgedUse / lastUnacknowledgedUseAt / remainingCodes), `acknowledgeRecoveryUse` (mutation: stamps every unacked row), `regenerateRecoveryCodesAfterUse` (mutation: regen path that doesn't require a fresh TOTP code, gated on a recent unacknowledged use being present so it can't be replayed without that proof). Both regen paths funnel through a shared `rotateRecoveryCodesForUser` so the deletion-then-insert transaction is identical.

  New global `<RecoveryCodeReminder>` ([components/recovery-code-reminder.tsx](monark/app/services/web/src/components/recovery-code-reminder.tsx)) mounted in [(authed)/layout.tsx](<monark/app/services/web/src/app/(authed)/layout.tsx>). Picks one of four modes from the status:
  - `acknowledge` (≥ 3 left + just used): strike-through animation over 5 mock `XXXX-XXXX-XXXX` lines (one picked at random per mount, gets `line-through` after 350ms with a 700ms transition) + "I struck it from my list" button.
  - `acknowledgeLow` (1-2 left + just used): same animation + "Regenerate now" primary CTA + "I struck it (regenerate later)" secondary. The regen path uses the no-TOTP-required `regenerateRecoveryCodesAfterUse` since the just-spent recovery code is itself proof of identity.
  - `suggestRegen` (1-2 left, no recent use): no animation ; suggests regen via the existing TOTP-gated path with an inline `<InputOTP>`. Dismissible for the session via "Not now" but server state re-opens it on next sign-in.
  - `mustRegenerate` (0 left): blocking ; `onPointerDownOutside` + `onEscapeKeyDown` prevented, the close X is hidden via `[&>button]:hidden`. Routes through whichever regen path the user has proof for.

  Post-regeneration the modal swaps to a fresh-codes view with the same `<pre>` codeblock + top-right copy button as the [account/totp-section.tsx](<monark/app/services/web/src/app/(authed)/account/totp-section.tsx>) flow ; user must explicitly click "I saved them" to dismiss. **i18n** (en + fr): new `account.totp.reminder.{usedTitle, usedSubtitle, usedAndLowSubtitle, lowTitle, lowSubtitle, mustRegenerateTitle, mustRegenerateSubtitle, strikeHint, totpPrompt, regeneratedTitle, regeneratedSubtitle, struckIt, regenLater, regenerateNow, regenerating, enterTotpToRegenerate, saving, notNow}` namespace.

  **Apply the migration locally**: `pnpm --filter @monark/db db:migrate:dev --name add_recovery_code_acknowledged_at`.
