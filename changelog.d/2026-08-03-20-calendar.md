- 2026-08-03: Calendar — added ICS export/import. `calendarRouter.events.exportIcs`/`importIcs` ([server/index.ts](monark/app/packages/calendar/src/server/index.ts)) generate/parse via the new `ics` (export) and `node-ical` (import) dependencies, both wired through a new [server/ics.ts](monark/app/packages/calendar/src/server/ics.ts). Export streams a real file download via a new route handler ([export/route.ts](<monark/app/services/web/src/app/(authed)/calendar/export/route.ts>)) reusing the server-side-tRPC-client pattern from `auth/confirm/route.ts`, rather than a fetch+blob dance. Import reads the chosen `.ics` file client-side as text (no upload/storage round-trip needed for a small text file) and creates events server-side, capped at 500/import ; any `VEVENT` carrying an RRULE imports as a flattened one-time event with a surfaced count, since recurring-event support lands in a later phase. Both actions live in each calendar's `···` menu in the sidebar ([calendar-sidebar.tsx](<monark/app/services/web/src/app/(authed)/calendar/calendar-sidebar.tsx>)). 8 new unit tests including a full generate→parse round-trip ([ics.test.ts](monark/app/packages/calendar/tests/ics.test.ts)).
