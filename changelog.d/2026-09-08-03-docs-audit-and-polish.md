- 2026-09-08: Documentation — **audited the published docs against the code, fixed what had drifted, and filled what was missing**. Every route the docs name was cross-checked against the routes that exist, which turned up two real drifts: `/setup` (there is no in-app setup wizard ; the api provisions the singleton org at boot from `INITIAL_ORG_*`, as [white-label.md](docs/technical-documentation/white-label.md) already said, so the docs contradicted each other) and `/admin/feature-flags` (no admin UI for flags exists ; overrides are `FeatureFlag` rows, the dev overlay shows resolved values, and `pnpm enable:dev-flags` flips the local set). The user guide had a whole "Setup gate" section describing the first ; a [deploy-checklist](docs/technical-documentation/deploy-checklist.md) step told an operator to trigger a webhook by toggling a flag in the second. Completeness: [admin.md](docs/user-guide/admin.md) documented eight of the ten `/admin` tabs, so **Automation integrations** and **Achievements** were added ; [navigation.md](docs/user-guide/navigation.md) listed four of five nav destinations and four of five account tabs ; [test-plan.md](docs/technical-documentation/test-plan.md) claimed two shipped e2e specs where eleven exist. Two shipped user-facing features had no user documentation at all and now do: the achievements gallery ([achievements.md](docs/user-guide/achievements.md), written from the `AchievementRule` model so the per-person / not-retroactive / no-conditions-means-unearnable behaviour is real) and public forms (admin side in [admin.md](docs/user-guide/admin.md), user side in [data.md](docs/user-guide/data.md)). Separately, 520 em-dashes across the 35 published docs were converted to house-style punctuation per [CLAUDE.md](CLAUDE.md), by context rather than blindly: definition lists take a colon, bracketed asides become parentheses, clause joins take `;`. Finally, `pnpm figures` ([figures.mjs](services/web/tools/screenshots/figures.mjs)) renders screenshot-harness stories at a tight element clip into [docs/assets](docs/assets), so the guides can carry figures that anyone can regenerate ; the records table and a kanban board are the first two.
