- 2026-07-04: Tooling — i18n key-parity CI gate. New [tools/check-i18n.ts](monark/app/tools/check-i18n.ts) (`pnpm check:i18n`, wired into the CI repo-checks job and the pre-PR gate) flattens every locale catalog under [services/web/src/messages](monark/app/services/web/src/messages) to its dotted key set and fails if any locale drifts from `en` : a key present in one locale but missing in another (which renders a silent runtime fallback), or a dead key present only in a translation. Value equality is intentionally **not** checked — many en/fr strings are legitimately identical (brand names, ICU skeletons, cognates), so comparing values would be noise. Locks in the current 1279-key en/fr parity and brings any future locale (e.g. `es.json`) under the same gate automatically. Second of the "make conventions executable" changes from [docs/review/collaboration.md](monark/app/docs/review/collaboration.md).
