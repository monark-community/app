- 2026-08-03: Automation / UI — **inline variable autocomplete.** Typing `{{` in a config field now opens a suggestion menu right under it (grouped by source — the trigger, each connected upstream step, workflow variables), filters as you type, navigates with ↑/↓, and inserts the chosen variable as a chip on Enter or click — so authors pick a connected node and its value without leaving the field or reaching for the side panel. Built into the shared [`VariableInput`](monark/app/packages/components/src/ui/variable-input.tsx) via a new `suggestions` prop; the menu only offers what's in scope at that step (the same ancestor-scoped set the picker uses). New exported pure helpers `activeQueryAt` (the unclosed `{{ …` the caret sits in) + `filterSuggestions`, whose logic — query detection (closed-token / multi-open / leading-space / empty) plus the accept-replaces-draft-with-chip DOM op — is verified headless (13 cases). The automation editor flattens its `variableGroups` into suggestions and threads them through `ConfigPanel` → `ConfigField` → every text / textarea / variable-mode field ([automation-editor.tsx](<monark/app/services/web/src/app/(authed)/automation/[id]/automation-editor.tsx>)). `@monark/components` + `web` typecheck + lint green; component README + the automation user guide updated.
