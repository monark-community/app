- 2026-07-06: DataTable — row-actions "…" menu no longer breaks the page layout on mobile. [Reported](monark/app/services/web/src/components/patterns/data-table/data-table.tsx): opening a row's action menu on a phone-width viewport visually shifted the whole page (header, nav, everything) instead of just the menu appearing. Root cause : `RowActionsMenu`'s `<DropdownMenu>` was Radix's default _modal_, which drives a body scroll-lock (`overflow: hidden`) on open ; on mobile a table with several columns is already a little wider than the viewport, silently masked by the page's own `overflow-x: clip`, and the scroll-lock's style swap disturbed that masking, blowing the layout viewport out to the table's full width. Fixed with `modal={false}` on the row-actions menu — same class of fix as the `CalendarChip` menu ([[radix-pointer-events-freeze]]) — since this menu never opens a follow-up modal itself, there's no menu→dialog handoff to worry about, and non-modal also means it can no longer contribute to that separate pointer-events-freeze failure mode either. `tsc` + `eslint` + 233 web tests green ; verified with Playwright at an iPhone-13 viewport (the layout viewport measurement returned to matching the true screen width across open/close, where before it inflated on open).
