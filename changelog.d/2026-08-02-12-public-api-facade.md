- 2026-08-02: Public API (facade) — the callable **`/api/v1` REST surface** over Data Models + records, authenticated by `@monark/api-keys` and gated behind a new `public-api.enabled` flag (off by default). The facade is a thin adapter, not a re-implementation : each route runs the SAME tRPC procedures the web app uses through a server-side caller ([services/api/src/public/caller.ts](monark/app/services/api/src/public/caller.ts)) built from the API key's `{ userId, activeOrganizationId }`, so all RBAC, per-record access, event emission, and validation are reused verbatim. Endpoints (v1) : `GET /me`, `GET /models`, `GET /models/{key}`, `GET /models/{key}/fields`, `GET/POST /models/{key}/records`, `GET/PATCH/DELETE /records/{id}`, plus an unauthenticated (but flag-gated) `GET /openapi.json`. Each route declares a coarse **scope** (`assertScope`, layered on top of the procedure's fine-grained permission) and validates query/body with zod, mapping `ZodError` / `TRPCError` / `AppError` to REST error codes ([mount.ts](monark/app/services/api/src/public/mount.ts), [routes.ts](monark/app/services/api/src/public/routes.ts)). **`@monark/public-api`** is now a library core module (no tRPC router) exporting the route-descriptor type, `assertScope`, a curated hand-rolled zod→JSON-schema step, and an OpenAPI-3 builder that derives the spec from the same descriptors that serve traffic (so it can't drift) ([openapi.ts](monark/app/packages/public-api/src/server/openapi.ts)). New shared **rate-limit primitive** `@monark/common/rate-limit` : a storage-agnostic token bucket whose pure step function is unit-tested and whose default Postgres store (new core `RateLimitBucket` table, migration `20260802130000_add_rate_limit_bucket`) shares the limit across api replicas (no Redis in the stack) ; the `/api/v1` middleware applies a per-key 5 req/s + burst-20 limit with `X-RateLimit-*` / `Retry-After` headers ([rate-limit.ts](monark/app/packages/common/src/rate-limit.ts)). 10 new unit tests (token-bucket math + OpenAPI builder + `assertScope`). `pnpm gen` + `typecheck` + `eslint` + all four gates green ; the `RateLimitBucket` migration applies with `db:migrate:dev`. End-to-end HTTP integration tests for the mount + the v1 keys management UI are the next milestone.
