- 2026-09-08: Tooling — **`pnpm agent pr` no longer refuses a clean branch because the local base ref is stale.** `branchAuthors` in [.claude/agentkit/lib/identity.mjs](.claude/agentkit/lib/identity.mjs) listed authors over `develop..HEAD` using the _local_ `develop`, so on a checkout whose `develop` is behind or carries commits that never reached the remote, the range picked up other people's commits and the push was refused with "these commits are not authored by the machine account: … ; rewrite them or push manually". Nothing was wrong with the branch: it read as a demand to rewrite someone else's history. It now resolves `origin/<base>` first and falls back to the local ref only when the remote one is absent, which is the rule `worktree.create` already follows one file over ("prefer the remote tip so a new branch never inherits stale local state"). Only the authorship range changed ; the PR base sent to GitHub still comes from `worktrees.baseBranch`, so the config value stays a plain branch name.
