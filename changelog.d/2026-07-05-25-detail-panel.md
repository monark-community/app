- 2026-07-05: Detail panel — resized width now persists per screen. The desktop detail-panel width was a single global preference (`detail-panel-width`), so widening the projects panel also widened the industries panel. [`TableDetailLayout`](monark/app/services/web/src/components/patterns/table-detail-layout.tsx) gained a `storageKey` prop that namespaces the persisted width (`detail-panel-width:<storageKey>`) ; the load effect keys on it (and resets when it changes) and the resize-end write targets it. Wired each list screen to its own key — `projects`, `industries`, `admin-users`, `admin-webhooks`, `admin-roles`, `admin-organizations` — so every panel remembers an independent width ; a caller that omits `storageKey` still falls back to the shared key. Updated the pattern's doc in [CLAUDE.md](monark/app/CLAUDE.md). `tsc` + `eslint` + 222 tests green.
