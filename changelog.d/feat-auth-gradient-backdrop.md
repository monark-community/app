- 2026-09-07: Auth screens — **an animated brand-gradient backdrop behind every pre-auth page**. Signin, signup, the TOTP challenge, forgot / reset password, check-email, and the `/auth/*` email-link landings all rendered the same centered column on a flat white sheet ; they now share a new [`AuthScreen`](services/web/src/components/auth-screen.tsx) shell that paints three oversized radial washes drifting slowly across one another, with the middle cleared back toward the page background so the card and its text keep a near-neutral ground. The washes are painted from `--primary`, so the backdrop follows the operator's org colour (the root layout already overrides that token when the singleton org sets one) instead of hardcoding the starter orange ; `color-mix` supplies the alpha, and the dark theme pulls the same tints back because they read far heavier on a near-black ground. Softness comes from each gradient's own falloff rather than `filter: blur()`, and the keyframes only touch `transform`, so the whole thing composites on the GPU ; `prefers-reduced-motion` freezes the drift and keeps the composition. Styles live in [globals.css](services/web/src/app/globals.css) ; the shell also de-duplicates the `min-h-screen` wrapper that all nine pages had pasted individually. A new `auth-screen` story in the [screenshot harness](services/web/tools/screenshots/stories.tsx) covers it in light and dark. The shell also owns the card and the heading, so the page title and subtitle sit inside the form surface and the brand mark is the only thing outside it, parked in the viewport's top-left corner ; the forms no longer wrap themselves in their own `Card`, and the brand mark reaches the shell as a prop so it stays a plain synchronous component the screenshot harness can mount.
