  - **`@monark/rbac` write-side** ([packages/rbac/tests/integration/write.test.ts](monark/app/packages/rbac/tests/integration/write.test.ts)). 11 cases. Three scope-guard cases on `assignRole` : SYSADMIN with a non-null orgId rejects (it's platform-tier only), ADMIN with a null orgId rejects (it's org-tier only), and a custom role granted at the wrong org rejects. Two happy-path acceptance cases. Three on the `alreadyActive` idempotency contract : a re-grant returns `alreadyActive=true` with the same assignmentId, no `rbac.role-assigned` event re-emission on the retry (the load-bearing "don't double-fire notification fan-out on a retried mutation" guarantee), and the first-grant event payload shape (assignmentId, userId, organizationId, roleId, roleKey, grantedById, reason, occurredAt). Two on `revokeRole` : full-payload `rbac.role-revoked` emission + the no-op behaviour when revoking a non-existent assignment. Captures via the in-memory event bus through `on("*", …)` ; `_resetHandlersForTesting` in `beforeEach` clears subscribers between specs.
