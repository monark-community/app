- 2026-07-26: Global search — modules are now discoverable in the command palette by default, and content search is a real extension point. Two fixes to one root cause (the palette hardcoded its own destination list + a calendar-only content branch, so Kanban and Data were absent). (1) **"Go to" now derives from the drawer nav.** [global-search/routes.ts](monark/app/services/web/src/components/global-search/routes.ts) builds its module destinations from `PRIMARY_NAV` (the drawer's single source of truth, [config/primary-nav.ts](monark/app/services/web/src/config/primary-nav.ts)) instead of a second hand-maintained copy, so Kanban + Data appear immediately and the two lists can never drift again ; labels reuse the drawer's own strings. (2) **New content-provider registry.** [global-search/search-providers.ts](monark/app/services/web/src/components/global-search/search-providers.ts) lists `SearchProvider`s — each a client component (`isActive(pathname)` + its own tRPC search) that renders a shared [`SearchResultsGroup`](monark/app/services/web/src/components/global-search/search-results-group.tsx). Migrated calendar's hardcoded branch into a `CalendarSearchProvider`, and added `KanbanSearchProvider` (cards) + `DataSearchProvider` (current model's records). Kanban gained a gated `cards.search` procedure ([index.ts](monark/app/packages/kanban/src/server/index.ts) + `searchCards` in [data.ts](monark/app/packages/kanban/src/server/data.ts), scoped to accessible boards) and a `?card=` deep-link so a searched card opens its editor ([kanban-shell.tsx](<monark/app/services/web/src/app/(authed)/kanban/kanban-shell.tsx>)) ; data records reuse the already-gated `records.list` search and deep-link via `?record=`. Documented both as a module-shipping default in [CLAUDE.md](monark/app/CLAUDE.md) (new "Navigation & global search" section + a DoD checklist item). New i18n (`globalSearch.groups.{kanban,data}`, en + fr ; dropped the now-derived `routes.calendar`). New kanban integration spec for `searchCards` (title match, board-name, soft-delete drop, empty-scope). `pnpm gen` + `tsc` (web + kanban) + `eslint` + `check:i18n` green.
