- 2026-07-26: Data tables — the per-row `…` actions menu is now **pinned to the right edge** of the row instead of trailing right after the last data column. In the shared [`DataTable`](monark/app/services/web/src/components/patterns/data-table/data-table.tsx) the actions column (header + body cell) is `position: sticky; right: 0`, so it stays flush-right when the columns don't fill the width and stays visible during horizontal scroll (wide tables) rather than sliding off. The pinned cell needs its own opaque background (a cell paints on top of the row's, so reusing the row's translucent tint directly would apply it twice — reading brighter in dark theme / the header black). The body actions cell layers the row's **real** translucent tint (`hover:bg-muted/30`, selected `bg-primary/10`) as an absolute fill over an opaque `bg-background` base, so it renders pixel-identically to a transparent sibling — exact even for the saturated selected tint (an opaque `color-mix` approximation of alpha-compositing visibly diverged there).
