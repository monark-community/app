- 2026-08-03: Automation / UI — **tap-to-open variable picker (replaces the `{{`-triggered inline menu for discoverability + mobile).** Picking a variable was gated behind typing `{{`, which was invisible in variable mode and — on mobile — put suggestions under the keyboard while the inspector's Variables panel scrolled off-screen, so authors couldn't tell what was available. New [`VariablePicker`](<monark/app/services/web/src/app/(authed)/automation/[id]/variable-picker.tsx>): a searchable, two-level list — **sources** (Trigger / each connected step by name / Workflow variables) that drill into their **variables** — rendered as a popover under the field on desktop and a **bottom sheet** on mobile (always visible, no keyboard fight), built on `Command` + `Popover`/`Sheet`. A **choice field toggled to variable** (`select` / `user` / `number` / …) now becomes a "Choose a variable…" trigger showing the current value as a chip instead of a bare text box ; **text/body fields** keep the chip input and gain a `{ }` button that opens the same picker (inserting at the caret via the field's handle) plus the existing `{{` autocomplete as a fast path. An empty state explains _why_ nothing's available (step not connected), and a search "use {ref} verbatim" row preserves deep-path references the declared outputs don't enumerate. Threaded `suggestions` (already computed) into the picker through `ConfigField` ([automation-editor.tsx](<monark/app/services/web/src/app/(authed)/automation/[id]/automation-editor.tsx>)) ; new `chooseVariable` / `variablePickerTitle` / `variableSearch` / `noVariablesAvailable` / `noVariablesMatch` / `useCustomVariable` i18n (en + fr). `web` typecheck + lint + `check:i18n` green ; user guide updated.
