- 2026-05-01: Branded password-reset email. New [supabase/templates/recovery.html](monark/app/supabase/templates/recovery.html) mirrors the `confirmation.html` chrome (orange header bar, wordmark, white card, footer) ; bilingual via `user_metadata.locale_preference`. Wired through `[auth.email.template.recovery]` in [supabase/config.toml](monark/app/supabase/config.toml). Link uses the token-hash URL form (`/auth/confirm?token_hash=…&type=recovery`) so the recipient lands directly on our app instead of double-hopping through Supabase's `/auth/v1/verify`. Carries the same 6-digit OTP fallback the signup confirmation email uses ; valid for one hour. Restart `pnpm supabase start` (or `pnpm supabase stop && pnpm supabase start`) to pick up the new template binding.
