- 2026-08-03: Calendar — added an Agenda view : a 4th `CalendarViewType` (day/week/month/agenda) showing a forward-chronological, day-grouped list of upcoming events with a "Load more" footer. New `listEventsPaginated`/`calendarRouter.events.listAgenda` ([data.ts](monark/app/packages/calendar/src/server/data.ts)) is genuinely cursor-paginated (`PaginationArgs`/`Paginated<T>`, `cursorFindArgs`/`toPage` from `@monark/common`) per the repo's "list methods paginate" convention — unlike day/week/month's already-accepted date-range-bounded exception, an "keep scrolling" agenda is exactly the access pattern that convention exists for. Wired into [calendar-shell.tsx](<monark/app/services/web/src/app/(authed)/calendar/calendar-shell.tsx>)'s view switcher (keyboard shortcut `A`) ; mobile still collapses it to Day view, same as week/month, since there's no way to switch into it from the mobile toolbar anyway. 2 new integration tests for the pagination boundary + the `from` cutoff.
