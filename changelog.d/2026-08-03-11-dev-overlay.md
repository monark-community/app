- 2026-08-03: Dev overlay — fits narrow screens + a movable anchor. The panel ([dev-overlay.tsx](monark/app/services/web/src/components/dev-overlay/dev-overlay.tsx)) was a fixed `w-96` (24rem) block that overflowed a phone viewport; it now carries `max-w-[calc(100vw-2rem)]`, clamping to the screen minus its 1rem gutter on each side. Added a corner picker ([anchor-toggle.tsx](monark/app/services/web/src/components/dev-overlay/anchor-toggle.tsx)) in the overlay header — a small dropdown that pins the toggle button + panel to any of the four viewport corners (top-left / top-right / bottom-left / bottom-right), persisted per-browser in `localStorage` (default bottom-right, loaded after mount so there's no hydration mismatch; the menu is `modal={false}` to avoid a stuck body pointer-events lock). New `devOverlay.anchor.*` i18n (en + fr). `tsc` + `eslint` + `check:i18n` green.
