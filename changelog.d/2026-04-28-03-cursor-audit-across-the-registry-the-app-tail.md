- 2026-04-28: Cursor audit across the registry + the app. Tailwind v4 dropped `cursor: pointer` on `<button>` and shadcn followed the spec on menu-style items (`cursor: default` to feel native), but the result reads broken on web — clickable surfaces don't tell you they're clickable. Reverted that across the board. **Registry** ([monark/ui/components/ui/](monark/ui/components/ui/)): `button.tsx`, `tabs.tsx` (TabsTrigger), `accordion.tsx` (AccordionTrigger), `toggle.tsx`, `checkbox.tsx`, `radio-group.tsx`, `select.tsx` (Trigger + Item), `command.tsx` (Item), `dropdown-menu.tsx` (Item / CheckboxItem / RadioItem / SubTrigger), `context-menu.tsx` (same surface), `menubar.tsx` (Trigger + SubTrigger + Item / CheckboxItem / RadioItem), `sidebar.tsx` (sidebarMenuButtonVariants), `connect-wallet.tsx` (custom trigger) all gain `cursor-pointer`. Items previously carrying `cursor-default` (the menu/select families) flipped to `cursor-pointer`. Form controls already had `disabled:cursor-not-allowed` ; left untouched. `switch.tsx` already had the right shape (`cursor-pointer disabled:cursor-not-allowed`) — used as the model for the rest. Resize cursors on `sidebar.tsx`'s rail kept as-is (correct semantic). `select.tsx` scroll-up/down buttons kept on `cursor-default` (auto-scroll on hover, not a click). **App-installed copies** ([services/web/src/components/ui/](monark/app/services/web/src/components/ui/)): `button.tsx`, `tabs.tsx`, `dropdown-menu.tsx` mirrored. **App custom components**: bell button, mark-all-read inline button + disabled-state, popover list rows ([notifications-bell.tsx](monark/app/services/web/src/components/notifications-bell.tsx)) ; filter All/Unread toggle, mark-read + dismiss inline buttons ([inbox.tsx](monark/app/services/web/src/app/account/notifications/inbox.tsx)) ; help-icon trigger next to category labels ([notifications-section.tsx](monark/app/services/web/src/app/account/notifications-section.tsx)) ; avatar edit trigger + disabled state ([profile-section.tsx](monark/app/services/web/src/app/account/profile-section.tsx)) ; sign-out and TOTP-cancel form buttons ([account/page.tsx](monark/app/services/web/src/app/account/page.tsx), [signin/totp/page.tsx](monark/app/services/web/src/app/signin/totp/page.tsx)) ; dev-overlay collapsible-section header ([collapsible-section.tsx](monark/app/services/web/src/components/dev-overlay/collapsible-section.tsx)). **What stayed**: anchors (`<a>`), since browsers already render pointer ; text inputs / textareas (text cursor is correct) ; native `<label>` over inputs (browser handles).
