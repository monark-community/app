- 2026-07-05: DataTable — the whole row is now clickable, not just the primary label. A click anywhere in a row activates its primary column ([data-table.tsx](monark/app/services/web/src/components/patterns/data-table/data-table.tsx)) — `router.push` on the primary `href`, else `primaryColumn.onSelect` — so opening a record no longer requires hitting the (often short) label. Rows only get the affordance (`cursor-pointer`) when the primary is actually actionable for that row (a link `href` or an `onSelect` ; e.g. archived rows with a `undefined` href stay inert). The handler yields to any real control inside the row (the primary link, the row-actions `…` button, inline links / inputs — matched via `closest(...)`) and bails on a text-selection drag, and the `…` trigger button now `stopPropagation`s its click so opening the menu never also activates the row. Inline links like the projects URL cell keep opening in their new tab without selecting the row. `tsc` + `eslint` green.
