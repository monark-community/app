- 2026-07-25: Forms — extended the label-left layout to the `AutoForm` / fields toolkit. [`FieldShell`](monark/app/services/web/src/components/fields/field-shell.tsx) (the wrapper behind every schema-driven field) now flips its label from above the control to a left 10rem column at the same `@md` container-query threshold as the hand-rolled [`FieldRow`](monark/app/services/web/src/components/patterns/field-row.tsx), so an `AutoForm` in a detail panel reads identically to the hand-rolled forms beside it. The control + help + error now stack together in a right-column wrapper, so a wrapping error / char-counter aligns under the control rather than the label. `richText` (WYSIWYG) and `longText` (textarea) opt out and always stack full-width — they need the row width for a usable editing area — and `boolean` is unchanged (already its own label-left / toggle-right settings row, never via `FieldShell`). [`AutoForm`](monark/app/services/web/src/components/fields/auto-form.tsx) wraps its fields in `@container` so the flip scopes to the form's own width (flips in a wide panel / full page, stacks on mobile). Verified with the `fields-form` screenshot story: desktop flips every field except Notes (richText) + Published (boolean); mobile stacks all. `eslint` green on the touched files.
