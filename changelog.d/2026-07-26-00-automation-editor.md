- 2026-07-26: Automation editor — two more mobile fixes. (1) **Can't add a node on a phone** : `addNode` / `onConnect` minted ids with `crypto.randomUUID()`, which is undefined in a non-secure context — so a phone hitting the LAN dev server over http threw and silently dropped the add. Replaced with a `genId()` helper that falls back to a `Math.random` id (client-only graph keys, same pattern as the webhook subscription-picker) in [automation-editor.tsx](<monark/app/services/web/src/app/(authed)/automation/[id]/automation-editor.tsx>). (2) **Zoom controls + minimap sat below the fold** : the full-height shells used `100vh`, which on mobile includes the retracted URL-bar and runs taller than the visible area, pushing React Flow's bottom-anchored chrome off-screen. Switched calendar / kanban / automation (list + editor) to `100dvh` (matching the data layout ; `dvh` tracks the visible viewport). `tsc --noEmit` + `eslint` green.
