- 2026-08-07: Wiki — **new extended module `@monark/wiki`: a Notion-like nested wiki** (org-wide tree of rich-text pages ; flag-gated `wiki.enabled`, default off). A `WikiPage` owns a nullable `parentId` (self-relation, `SetNull`) + integer `position`, so pages nest arbitrarily deep as an **adjacency list walked in application code** — no recursive CTE ([data.ts](monark/app/packages/wiki/src/server/data.ts): `getAncestors` for the breadcrumb, `collectSubtree` for move / delete / restore). Siblings order in **gaps of 10** (the house kanban / data-models pattern) ; `movePage` reparents + reindexes in a transaction behind a **cycle-guard** that rejects moving a page under its own descendant (`ValidationError`), and a moved page's subtree rides along. Delete / restore operate on the **whole subtree** (`softDeleteSubtree` / `restoreSubtree` via `deletedAt`), and the `wiki.page-deleted` event carries the full `pageIds[]`. **Big-5:** RBAC `wiki.read/create/update/delete` (org-wide, no per-page ACL in v1 — a conscious scope choice) ; four domain events (`page-created/-updated/-moved/-deleted`, webhook-subscribable) ; `wiki.enabled` flag ; notifications N/A. The migration owns its fragment `packages/wiki/prisma/wiki.prisma` (`20260807063256_add_wiki_pages`), assembled by `pnpm gen:schema`. **Web** ([app/(authed)/wiki](<monark/app/services/web/src/app/(authed)/wiki>)): a server-gated section shell with the tree sidebar (expand-state persisted, auto-expands the active page's ancestors ; hover **+** to add a sub-page, **⋯** menu for move / duplicate / delete), a mobile drawer, a **Move to…** picker (v1 reparent/reorder ; drag is a fast-follow), and a page editor reusing the shared `RichTextEditor` with **debounced autosave**. Discoverability via a `PRIMARY_NAV` entry + a `SEARCH_PROVIDERS` content provider backed by `wiki.pages.search`. Docs: module [README](monark/app/packages/wiki/README.md), [user guide](monark/app/packages/wiki/docs/user-guide.md), internals [wiki.md](monark/app/docs/technical-documentation/wiki.md). Enabled on the dev instance via [enable-dev-flags.ts](monark/app/tools/enable-dev-flags.ts). Integration tests cover positions / ancestors / the move cycle-guard / subtree soft-delete + restore / org-scoped search ([wiki-data.test.ts](monark/app/packages/wiki/tests/integration/wiki-data.test.ts)).
