# Save a view

Save a query you run often so you can reapply it in one click. Views are available where your model has the query bar.

1. Type your query in the query bar, for example `status:open assignee:@me`.
2. Open **Views** and choose **Save current query…**
3. Name the view. To let everyone with access to the model use it, turn on **Share with everyone**.
4. Click **Save**.

To apply a view, open **Views** and pick it. Each view is marked as personal (only you see it) or shared.

## Delete a view

Open **Views**, click the bin icon next to the view, then **Delete**. You can only delete views you created.

Good to know: a view stores the query, not the results. A view using `@me` or `@today` shows each person their own records, up to date, every time.
