# Edit many records at once

Set one field to the same value on several records in one go, for example to reassign a batch or close a set of tickets. Bulk editing is a separate permission; if you can't select rows, your role doesn't include it.

1. Tick the checkbox on each record you want to change. To select every record on the page, tick the checkbox in the header. A bar appears with the number selected.
2. Click **Edit field**.
3. Choose the field, then enter the new value.
4. Click **Apply to N records**.

If the selected records hold different values for that field, you're warned before anything changes: applying overwrites all of them. Formula fields can't be bulk edited.

To drop the selection, click **Clear**.
