# Find records

Narrow a model down to the records you need.

1. Open **Data** in the navigation rail and pick a model. Its records appear in a table, with each record's title pinned in the first column.
2. Narrow the list. Depending on how your organization is set up, you'll see one of two tools at the top of the table:
   - **A search box and a Filters menu.** Type in the search box to match record titles. Open **Filters** to add conditions on any field, such as a status or a date range.
   - **A query bar** (shows the hint _Filter… e.g. status:open priority:>3_). Type conditions like `status:open assignee:@me`. Suggestions appear as you type field names and values. See [Query syntax](../../reference/query-syntax.md) for everything you can write.
3. Click any row to open the record.

![The records table: one row per record, with the title column pinned first and each field shown by its type.](../../assets/records-table.png)

## Sort and choose columns

- Open **Sorting** to order by one or more fields.
- Open **Columns** to show, hide or reorder columns. **Reset columns** goes back to the default.

Your sorting and column choices are remembered in this browser.

## Include deleted records

Deleted records are hidden by default. In **Filters**, set **Status** to **Include deleted** to see them.

Good to know:

- Each model has its own address, so you can bookmark it or send the link to a colleague.
- You only ever see records your role allows. Some records may be restricted to specific roles.
