# Manage files

Find, download or delete the files uploaded in your organization, most of them from **File** and **Attachments** fields on records. Files are kept in storage buckets, each with its own size and type limits. If the **Files** tab shows a "not found" page, file storage isn't enabled for your organization.

1. In **Admin**, open **Files**.
2. Pick a bucket, or **All buckets**, to list its files with their size and upload date.
3. Open a file's **…** menu and choose **Download**, or **Delete** and confirm. Deleting removes the file permanently.

## Upload a file

Pick a bucket, then click **Upload file**.

## Create a bucket

1. Click **New bucket**.
2. Enter a **Name**: lowercase letters, numbers and dashes, 3 to 63 characters.
3. Optionally set a **Max size (MB)** and the **Allowed types**, such as `image/png, application/pdf`.
4. Click **Create bucket**.

Good to know: only a system administrator can make a bucket public, so that its files are served from a public address.
