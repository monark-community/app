# Integrations

Connect Monark to the other systems your organization uses: store the credentials automations need, link outside services, send events out, and give scripts their own identity for the API.

Admins only. If you hold the Administrator role, **Admin** appears at the bottom of the navigation rail (in the menu on a phone); these pages start there.

- [Store a secret](store-a-secret.md): keep an external token or API key where automations can use it but no one can read it.
- [Connect GitHub, Telegram, X or Discord](connect-github-telegram-x-or-discord.md): link a service your automations trigger on or act through.
- [Send events to a webhook](webhooks.md): have Monark notify another system whenever something happens.
- [Check webhook deliveries](check-webhook-deliveries.md): see what was sent, find out why a delivery failed, and send it again.
- [Create a service account](create-a-service-account.md): give a script or integration its own API keys and roles.
