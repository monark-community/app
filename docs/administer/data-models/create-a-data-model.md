# Create a data model

A data model is one of your organization's databases, such as Clients, Projects or Bug reports; each row in it is a record. Create the model, then give it fields.

1. In **Admin**, open **Data Models** and click **New Data Model**.
2. Enter a **Name**, such as "Bug report", and optionally a **Description**.
3. Click **Create**. The model's editor opens.

The model starts with one field, its title, which every record has. Add the others next. People whose role can read records find the new model under **Data** in the navigation rail.

The model's web address comes from the name you first give it. Renaming it later under **Settings** doesn't change the address, so links keep working.

## Delete or restore a model

1. In the **Data Models** list, open the model's **…** menu and choose **Delete**, then confirm. Its fields and records go with it.
2. To bring it back, set the list's **Status** filter to **Include deleted**, open the model's **…** menu and choose **Restore**.
