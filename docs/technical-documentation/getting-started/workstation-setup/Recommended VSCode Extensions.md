# Recommended VSCode Extensions

### 🧱 Core Extensions for Smart Contracts

These are must-haves if you're working with Solidity, Foundry, or Hardhat.

| Extension                                                                                              | Description                                        |
| ------------------------------------------------------------------------------------------------------ | -------------------------------------------------- |
| [**Solidity by Juan Blanco**](https://marketplace.visualstudio.com/items?itemName=JuanBlanco.solidity) | Syntax highlighting, linting, compilation support. |

---

### 🖥 Frontend & dApp Stack

For React/Next.js frontends integrated with Ethers, Wagmi, RainbowKit, etc.

| Extension                                                                                                      | Description                                                           |
| -------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| [**ESLint**](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint)                       | Catch issues and enforce best practices.                              |
| [**Prettier**](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)                     | Code formatter to keep things consistent.                             |
| [**Tailwind CSS IntelliSense**](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss) | Useful if you're using Tailwind in your frontend, which we recommend. |
