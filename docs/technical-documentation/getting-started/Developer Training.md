# 🧑‍🎓 Starter Trainings

## 🚀 Cyfrin Updraft

Cyfrin Updraft offers a rich collection of blockchain training programs that are directly applicable to Monark’s developer onboarding and education goals. It includes courses on smart contract security, protocol development, and advanced Web3 concepts, making it an ideal resource for both beginners and experienced developers in our ecosystem.

We recommend you check the following training before starting your projects :

- [Blockchain Basics](https://updraft.cyfrin.io/courses/blockchain-basics): Core principles (Optionnal if you’ve had a blockchain class)
- [Solidity](https://updraft.cyfrin.io/courses/solidity): Ethereum Smart Contract Development
- [Foundry](https://updraft.cyfrin.io/courses/foundry) : Rust-based Ethereum development toolkit for building, testing and deploying smart contracts.

You can find more Cyfrin Updraft blockchain related training [here](https://updraft.cyfrin.io/courses).
