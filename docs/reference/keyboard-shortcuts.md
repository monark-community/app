# Keyboard shortcuts

Every keyboard shortcut in the app. On Windows and Linux, use Ctrl where the table shows ⌘. Single-letter shortcuts don't fire while you're typing in a field.

## Anywhere

| Keys  | Does                                              |
| ----- | ------------------------------------------------- |
| ⌘ K   | Open search                                       |
| ⌘ J   | Open or close the assistant, where it's turned on |
| Esc   | Close the open dialog, drawer, panel or menu      |
| Tab   | Move to the next button, link or field            |
| Enter | Activate the focused button or link               |

## Search

| Keys  | Does                        |
| ----- | --------------------------- |
| ↑ ↓   | Move through the results    |
| Enter | Open the highlighted result |

## Assistant

| Keys        | Does              |
| ----------- | ----------------- |
| Enter       | Send your message |
| Shift Enter | Start a new line  |

## Automation editor

| Keys                | Does                                                               |
| ------------------- | ------------------------------------------------------------------ |
| N                   | Open **Add node**                                                  |
| Delete or Backspace | Remove the selected node or connection                             |
| `{{`                | In a text field, suggest values from the trigger and earlier steps |

## Calendar

| Keys | Does                                |
| ---- | ----------------------------------- |
| D    | Day view                            |
| W    | Week view                           |
| M    | Month view                          |
| A    | Agenda view                         |
| T    | Jump to today                       |
| ← →  | Previous or next day, week or month |
