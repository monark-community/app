# Data (records)

**Data Models** are custom databases your organization's admins define ; a "Projects" table, a "Universities" table, whatever your team needs. Each model has its own fields ; the rows are called **records**. This page is about working with records day-to-day. (Defining the models + fields themselves is an admin task, covered under [Data Models in the admin guide](../admin/data-models.md).)

Reach it from the **Data** entry in the navigation rail. Which models you see (and whether you can view, add, edit, or delete their records) depends on the permissions your role has been granted for each model.
