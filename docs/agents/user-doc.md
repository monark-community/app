# User-documentation guidelines

Superseded by the **`monark-docs` skill** at [.claude/skills/monark-docs/](../../.claude/skills/monark-docs/SKILL.md), which covers all published docs (user, admin, developer, operator) : where a page goes, its type and template, the house style, and an audit procedure with a linter.

The rules this file used to hold still apply and now live there : write for the reader at the altitude of the interface, ground every statement in shipped behaviour (check labels in `services/web/src/messages/en.json`), state gating in the reader's terms, and keep extended-module docs inside the package.
